## Decisions Made

- **Citations table deferred**: Research schema showed 11 tables including `citations`. Plan explicitly specifies 10 tables. Citations schema is supported by FK references (resolved_case_id) but the table itself is not created in Phase 1.
- **Hand-written migration over autogenerate**: Autogenerate was not used because the execution environment has no live database. Hand-written migration provides explicit control over FK dependency order and avoids Pitfall 2 (empty migrations when models not imported before autogenerate runs).
- **test_no_create_all_in_codebase scope**: Test searches api/, alembic/, pipeline/ directories (not tests/) to avoid false positives from test files that reference "create_all" in assertions.
- **SideEnum values uppercase, PipelineRunStatus lowercase**: Matches the research schema exactly — BENCH/ADVOCATE/UNKNOWN uppercase because they come directly from raw speaker label conventions; pending/running/etc. lowercase for idiomatic status field conventions.
