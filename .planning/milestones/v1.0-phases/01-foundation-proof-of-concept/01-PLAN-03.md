    Create pipeline/commands/ingest.py implementing `async def run_ingest(args)`.

    The function must:

    1. **URL validation (SSRF mitigation):** Parse the --url value with urllib.parse.urlparse. Reject any URL where the scheme is not "https" or the netloc does not end with "supremecourt.gov". Raise ValueError with message "Only supremecourt.gov URLs are accepted" — do not call httpx before this check.

    2. **Derive slug and local PDF path:**
       - slug = args.case_name.lower().replace(" ", "-").replace(".", "").replace(",", "") (e.g., "obergefell-v-hodges")
       - pdf_filename = f"{args.primary_docket}-q{args.question}.pdf"
       - pdf_path = Path("data/pdfs") / pdf_filename
       - Create data/pdfs/ if it does not exist

    3. **Download PDF (idempotent):**
       - If pdf_path already exists, skip download (PIPE-02: immutable after initial ingest)
       - Otherwise, download with httpx.AsyncClient(follow_redirects=True, timeout=60.0)
       - Write bytes to pdf_path using pdf_path.write_bytes(response.content)
       - Print: f"Downloaded {pdf_filename} ({len(response.content)} bytes)"

    4. **Create DB records (async session from pipeline.db.get_session):**
       Open a single async session for all record creation:

       a. **Case records (idempotent):** For the primary docket (args.primary_docket) and each docket in args.dockets (if any):
          - Check if a Case row exists with this docket_number
          - If not: create Case(docket_number=docket, docket_number_norm=docket.replace("-", ""), case_name=args.case_name, term_year=int(args.argued_date.split("-")[0]), slug=slug + ("-" + docket if docket != args.primary_docket else ""))
          - For the primary docket, slug = slug (e.g., "obergefell-v-hodges")
          - For consolidated dockets, slug = slug + "-" + docket (e.g., "obergefell-v-hodges-14-562")
          - Use merge/upsert pattern: SELECT first, INSERT if not found (no ON CONFLICT needed with this check — but be transactional)

       b. **Argument record:** Create Argument(argued_date=date.fromisoformat(args.argued_date), question_number=args.question). Flush to get the argument.id.

       c. **CaseArgument rows:** For each case created/found, create CaseArgument(case_id=case.id, argument_id=argument.id, is_lead=(docket == args.primary_docket)) — only if the row does not already exist (check before insert to handle re-run idempotency).

       d. **PipelineRun record:** Create PipelineRun(argument_id=argument.id, step="ingest", status=PipelineRunStatus.COMPLETED, pdf_path=str(pdf_path), pdf_url=args.url)
          - Set status directly to COMPLETED (ingest is synchronous; no async processing required)
          - Print: f"Ingest complete. pipeline_run.id = {run.id}"

       e. Commit the session.

    5. Import all models from api.models.models. The pipeline shares the same models as the API.

    Create data/pdfs/.gitkeep to ensure the directory is tracked by git (with an accompanying .gitignore entry excluding all files except .gitkeep).

| Operator → ingest CLI | Operator provides --url, --case-name, --argued-date, --primary-docket args |
| ingest CLI → supremecourt.gov | httpx download; validated before connection |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Elevation | httpx PDF download | mitigate | URL validated against supremecourt.gov before any httpx call (urlparse netloc check). Scheme must be https. Rejects: http://, file://, ftp://, any non-scotus host. Code: `if not parsed.netloc.endswith("supremecourt.gov"): raise ValueError(...)` |
| T-03-02 | Tampering | Immutable PDF storage | mitigate | PDF write uses `pdf_path.write_bytes()` only when file does not already exist. Re-running ingest skips download if file present. No code path modifies an existing PDF. |
| T-03-03 | Tampering | Duplicate consolidated dockets | mitigate | CaseArgument composite PK (case_id, argument_id) at DB level prevents duplicates. Ingest checks for existing rows before insert. |
</threat_model>
