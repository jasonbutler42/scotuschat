    ```python
    from contextlib import asynccontextmanager
    from sqlalchemy.ext.asyncio import create_async_engine, async_sessionmaker, AsyncSession
    from fastapi import FastAPI
    from typing import AsyncGenerator, Optional

    engine = None
    AsyncSessionLocal = None

    @asynccontextmanager
    async def lifespan(app: FastAPI):
        global engine, AsyncSessionLocal
        engine = create_async_engine(
            settings.database_url,
            connect_args={"statement_cache_size": 0},   # REQUIRED for PgBouncer — in connect_args NOT top-level
            pool_size=5,
            max_overflow=10,
            pool_pre_ping=True,
            echo=False,
        )
        AsyncSessionLocal = async_sessionmaker(engine, expire_on_commit=False)  # expire_on_commit=False prevents MissingGreenlet
        yield
        await engine.dispose()

    async def get_db() -> AsyncGenerator[AsyncSession, None]:
        async with AsyncSessionLocal() as session:
            yield session
    ```

    Create api/routers/arguments.py following the FastAPI Router Pattern from RESEARCH.md:

    ```python
    from fastapi import APIRouter, Depends, HTTPException
    from sqlalchemy.ext.asyncio import AsyncSession
    from api.core.database import get_db
    from api.services import arguments as argument_service
    from api.schemas.utterance import ArgumentUtterancesResponse

    router = APIRouter(prefix="/arguments", tags=["arguments"])

    @router.get("/{argument_id}/utterances", response_model=ArgumentUtterancesResponse)
    async def get_utterances(argument_id: int, db: AsyncSession = Depends(get_db)):
        result = await argument_service.get_argument_with_utterances(db, argument_id)
        if result is None:
            raise HTTPException(status_code=404, detail="Argument not found")
        return result
    ```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| SvelteKit server → FastAPI | Server-side fetch only; FASTAPI_BASE_URL never reaches browser |
| FastAPI → PostgreSQL | SQLAlchemy ORM; all queries parameterized; argument_id is an integer path param |
| Browser → SvelteKit | Read-only; no user input accepted in Phase 1 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Tampering | SQL injection via argument_id | mitigate | argument_id is declared as `int` in FastAPI path parameter. FastAPI validates and rejects non-integer values (422 Unprocessable Entity). SQLAlchemy ORM parameterizes all queries — no string interpolation into SQL. |
| T-05-02 | Information Disclosure | FASTAPI_BASE_URL exposed to browser | mitigate | +page.server.ts imports from `$env/static/private` only. SvelteKit does not bundle private env vars into the client JS bundle. Enforced by: grep for PUBLIC_FASTAPI in app/src/ returns no results. |
| T-05-03 | Information Disclosure | FastAPI internal errors exposed | mitigate | FastAPI's default exception handler returns {"detail": "..."} without stack traces in production mode. debug=False is the default Settings value. |
</threat_model>
