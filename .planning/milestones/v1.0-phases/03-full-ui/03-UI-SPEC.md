## Spacing Scale

Declared values (all multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, gap between sequence number and speaker label in bubble header row |
| sm | 8px | Compact element spacing — gap between avatar and speaker name, margin-bottom on bubble header row, roster column item gap, section rail button margin-bottom |
| md | 16px | Default element spacing — bubble horizontal padding, section rail button horizontal padding, case list card padding, header bar horizontal padding |
| lg | 24px | Same-speaker turn gap in utterance stream, section rail top padding, header bar vertical padding, case list page top padding |
| xl | 32px | Different-speaker turn gap in utterance stream, section rail vertical padding between label groups |
| 2xl | 48px | Page-level top/bottom padding for chat column, stage direction top/bottom margins |
| 3xl | 64px | Not used in Phase 3 |

Exceptions:
- Avatar circle: 32px diameter (width + height) — driven by D-07 decision, not spacing scale

- Chat bubble border-left accent: 3px — visual affordance, not spacing
- Section rail width: 180px — layout dimension per D-01, not spacing scale
- Mobile breakpoint: 768px — responsive threshold per D-03

## Typography

Four roles are active in Phase 3. Weights are exactly 2: 400 (regular) and 600 (semibold).

| Role | Size | Weight | Line Height | Usage | Source |
|------|------|--------|-------------|-------|--------|
| Heading | 20px | 600 | 1.2 | Argument header case name (h1); case list item case name; case list page heading | `+page.svelte` existing |
| Body | 16px | 400 | 1.6 | Utterance text in ChatBubble | `ChatBubble.svelte` existing |

| Label | 13px | 600 (speaker name, active rail, roster column headers) / 400 (sequence, role, inactive rail) | 1.2 | Speaker name, sequence number, role tag in bubble header row; section rail button text; roster column headers ("Bench" / "Advocates") | `ChatBubble.svelte` existing |

Avatar initials exception: 12px, weight 600, color `#0f1117` — inside a 32px circle, rendered inline on the avatar element only. This is not a declared type role; it does not count toward the 4-size scale.

### 60/30/10 Split

- **60% dominant:** `#0f1117` — page background, all outer wrappers
- **30% secondary:** `#1e293b` — all surface elements: header bar, chat bubbles, case list cards, section rail, active rail button background
- **10% accent:** `#93c5fd` (advocate blue) — reserved exclusively for: (1) advocate speaker name label text, (2) advocate avatar circle background, (3) active section rail button left-border indicator (3px `border-left`). Never applied to bench elements, headings, or body text.

### Apolitical Framing — Color Enforcement

- Bench and advocate bubbles: identical background (`#1e293b`), identical border (`#334155`), identical text color (`#e2e8f0`)
- Side differentiation: layout position only (bench left, advocate right per D-05) — never background color
- Roster columns: both use `#94a3b8` for speaker name text — identical treatment regardless of side
- Section rail active indicator: uses `#93c5fd` border-left — this is not a speaker-side color in this context; it represents the reader's navigation position

## Layout Contracts

### Two-Column Argument View

The outer wrapper changes from single-column centered to CSS Grid:

```
grid-template-columns: 180px 1fr
```

- Rail column: `position: sticky; top: 0; align-self: start; padding: 24px 16px`
- Chat column: no `max-width` cap (grid handles sizing); `padding: 48px 24px`
- Mobile (< 768px): rail column `display: none`; chat column spans full width

Header bar remains full-width above the grid (not inside the grid columns).

**Primary visual anchor:** The chat utterance stream occupying the `1fr` grid column. All other elements (rail, header) are subordinate framing around this stream. No competing focal points at the same visual weight.

### Section Rail (SectionRail.svelte)

- Width: 180px (set by grid column, not component)
- Background: transparent (grid cell bg is `#0f1117`)
- Each section button: `display: block; width: 100%; text-align: left; padding: 8px 12px; margin-bottom: 4px; border: none; cursor: pointer; border-radius: 4px`
- Inactive state: `background-color: transparent; color: #94a3b8; border-left: 3px solid transparent`
- Active state: `background-color: #1e293b; color: #e2e8f0; border-left: 3px solid #93c5fd`
- Label text: title case from lowercase `section_hint` — "Petitioner", "Respondent", "Rebuttal", "Amicus"
- Font: 13px, weight 400 (inactive) / weight 600 (active)
- Scroll-spy: IntersectionObserver with `rootMargin: '-40% 0px -55% 0px'`; guarded by `browser` from `$app/environment`

### Argument Header with Roster (UI-04)

The header bar gains a speaker roster below the existing case name + subline:

```
[Header bar: #1e293b, border-bottom #334155, padding 16px 24px]
  [h1: case_name — 20px, weight 600, #e2e8f0]
  [subline: No. {docket} · Argued {date} · Question {n} — 14px, weight 400, #94a3b8]
  [Roster: two columns, margin-top 16px]
    [Bench column]          [Advocates column]
      Speaker Name            Speaker Name
      (14px, 400, #94a3b8)    (14px, 400, #94a3b8)
```

Roster two-column layout: `display: grid; grid-template-columns: 1fr 1fr; gap: 16px; margin-top: 16px`

Column headers: "Bench" / "Advocates" — 13px, weight 600, `#475569` (muted label, not a primary heading)

Speaker names in roster: 14px, weight 400, `#94a3b8` — identical for both columns (apolitical framing).

### Avatar Circle (ChatBubble — D-06/D-07/D-08)

Position: flex row inside bubble header — `[avatar circle] [gap: 8px] [sequence] [gap: 4px] [speaker name] [role tag]`

```
width: 32px
height: 32px
border-radius: 50%
background-color: #94a3b8 (bench) | #93c5fd (advocate)
display: flex; align-items: center; justify-content: center
font-size: 12px; font-weight: 600; color: #0f1117
flex-shrink: 0
```

Avatar initials: 12px inline — not a declared type role.

Initials algorithm: first letter of first word + first letter of last word of `displayName`, uppercased. Single-word names: first two characters uppercased. Applied after `displayName = utterance.speaker_name ?? utterance.raw_speaker_label ?? ''`.

## Interaction Contracts

### Scroll-Spy (UI-08)

- Trigger: `IntersectionObserver` on each section anchor element
- Anchor elements: `<div id="section-{hint}-{sequence}">` wrapping the first utterance of each section
- Active section: `$state activeSection` — updated when a section anchor enters the intersection zone
- rootMargin: `-40% 0px -55% 0px` (tunable; creates ~5% viewport band around center)
- SSR guard: `if (!browser) return;` as first line of `$effect`
- Cleanup: return `() => observers.forEach(o => o.disconnect())` from `$effect`
- Section labels in rail: derived `$derived` from `data.utterances.filter(u => u.section_hint !== null && !u.is_stage_direction)`

### Smooth Scroll on Rail Click

- Click handler: `document.getElementById(anchorId)?.scrollIntoView({ behavior: 'smooth' })`
- No JS scroll library; uses native browser `scrollIntoView`

### Case Navigation Model (D-09)

- Case list item links to `/cases/{case.slug}` (not directly to argument)
- `/cases/[slug]` page: if single argument, `redirect(307, /cases/{slug}/arguments/{id})`; if multiple, render argument picker
- Enables Q2 load without code changes
