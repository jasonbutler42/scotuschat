## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser logout POST → server action | Authenticated request to revoke the current session |
| admin layout → future-phase routes | Placeholders must NOT be live links (prevent 404 / premature access) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-11 | Tampering | session not invalidated on logout | high | mitigate | logout action deletes cookie with matching `path: '/'`; deleted cookie cannot pass verifySession on next request; guard then redirects to login (Task 1) |
| T-06-12 | Elevation of Privilege | logout path mismatch leaves cookie | medium | mitigate | cookies.delete path '/' explicitly matches sessionCookieOptions set path '/' so the browser actually drops it (Task 1) |
| T-06-13 | Spoofing | disabled nav links navigate to unbuilt routes | low | mitigate | Pipeline Runner / People Editor rendered as `<span aria-disabled="true">`, never `<a href>` — no navigation, no 404, no premature route access (Task 2) |
| T-06-14 | Information Disclosure | admin layout leaks public nav/context | low | mitigate | Admin layout is isolated (D-08) and does not import the public `+layout.svelte`; no Cases link or public context rendered (Task 2) |
| T-06-SC | Tampering | npm/pip/cargo installs | low | accept | No new package installs — uses @sveltejs/kit and existing app.css only; no supply-chain surface added |
</threat_model>
