<objective>
Wire the admin-job service functions from Plan 01 into FastAPI routes on the existing `/api/admin` router: create-job (URL or file upload), the single poll endpoint with the step-advance side effect (D-05/D-06), the history list, the resolve-continue endpoint (D-14/PIPE-16), and inline person creation (D-13). The router-level `verify_admin_token` dependency already protects every route.

Purpose: This is the HTTP surface the SvelteKit pages call. The poll endpoint is the only place that decides whether to spawn the next subprocess, using the atomic guards so concurrent polls never double-spawn (Pitfall 4). The next step's `--run-id` is re-derived on every poll via `get_run_id_for_step`, so a job resumes correctly after the operator closes and reopens the browser (PIPE-17).
Output: `api/routers/admin.py` extended with five new routes (no new files).
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Operator form input → FastAPI | pdf_url string and uploaded file bytes are untrusted; cross into job creation and subprocess spawn |
| FastAPI → pipeline subprocess | argv only; shell=False |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Spoofing/Elevation | `POST /jobs` pdf_url (SSRF) | mitigate | `_validate_pdf_url` enforces https + `supremecourt.gov` BEFORE create_job and spawn; pipeline `_validate_url` is the second layer |
| T-07-04 | Tampering | upload file type | mitigate | reject `content_type != application/pdf` with 422 before upload/spawn |
| T-07-05 | Elevation | unauthenticated job creation | mitigate | all routes inherit router-level `verify_admin_token` dependency (no per-route auth needed) |
| T-07-06 | DoS | concurrent polls double-spawn parse | mitigate | atomic UPDATE-WHERE rowcount guard (Plan 01); spawn only when guard returns True |
| T-07-07 | Information Disclosure | error bodies | accept | resolve 422 returns the validation message (person id not found) — low sensitivity, no secrets; admin-only route |
</threat_model>
