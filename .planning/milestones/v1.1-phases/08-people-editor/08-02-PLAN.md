## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| SvelteKit → FastAPI admin routes | X-Admin-Token authenticated; untrusted person_id path param and PATCH body cross here |
| PATCH body → people/court_tenures rows | operator-supplied name/role/bio/photo/tenure data written to DB |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-AC | Spoofing/Elevation | all new admin routes | mitigate | Router-level Depends(verify_admin_token) inherited by every new route; Task 3 asserts 401 without token (ASVS V4) |
| T-08-IDOR | Tampering | PATCH/GET /people/{id} | mitigate | get_person_detail/update_person return None for unknown id → router raises 404; no write to a nonexistent/wrong person |
| T-08-MASS | Tampering | PATCH /people/{id} body | mitigate | PersonUpdate schema exposes ONLY full_name, role_id, bio_text, photo_url, tenures — over-posting other Person columns is impossible (ASVS V5) |
| T-08-SQLI | Tampering | all queries | mitigate | SQLAlchemy ORM parameterized queries only; no string-built SQL |
| T-08-DATE | Tampering | tenure date parsing | mitigate | datetime.date.fromisoformat validates ISO format; malformed date raises ValueError → 422 before any DB write (Pitfall 6) |
| T-08-NULL | Tampering | incomplete filter correctness | mitigate | empty-string bio/photo normalized to None on write so `IS NULL` filter is accurate (Pitfall 5) |
| T-08-SC | Tampering | package installs | mitigate | No new pip packages this phase (RESEARCH.md); supply chain unchanged |
</threat_model>
