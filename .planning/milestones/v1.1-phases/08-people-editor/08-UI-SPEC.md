# Phase 8 — UI Design Contract

> Visual and interaction contract for the people-editor admin pages.
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.

> Phase 8 extends the Phase 7 design contract without introducing new tokens.

## Spacing Scale

Declared values (multiples of 4 only). Carried forward from Phase 7 UI-SPEC — no new exceptions.

| Token | Value | Usage in Phase 8 |
|-------|-------|-----------------|
| xs | 4px | Icon gaps, chip gap spacing, label-to-chip gap |
| sm | 8px | Input padding (vertical), label-to-input gap, button internal padding (vertical), between chips |
| md | 16px | Field margin-bottom, button padding (horizontal), card section gap |
| lg | 24px | Card padding, section heading margin-bottom, content gap between sections |
| xl | 32px | Card padding (form card reference from Phase 7), section separator margin |
| 2xl | 48px | Page content area top padding (`padding: 48px 24px` — matches Phase 7 exactly) |
| 3xl | 64px | Not used in Phase 8 pages |

Exceptions:
- Minimum touch target: 44px height on all primary action buttons (WCAG 2.5.5) — carried from Phase 6–7.
- Table row action buttons: 32px min-height acceptable (same as Phase 7 DiscrepancyTable action buttons).
- Toggle switch: 24px height, 44px wide (CSS-only toggle — not a primary action).

3. Active/checked state of the incomplete toggle switch (track fill when on)

## Component Inventory

### New components (Phase 8 only — hand-authored, no library)

**PeopleTable** (`/admin/people`)
- Outer container: `width: 100%; border-collapse: collapse;`
- Header row: `font-size: 14px; font-weight: 400; color: #94a3b8; border-bottom: 1px solid #334155; padding: 8px 0;`
- Data rows: `font-size: 16px; color: #e2e8f0; border-bottom: 1px solid #334155; padding: 12px 0;`
- Columns: Name | Role | Missing fields | Edit
- Name column: 40% width — primary identifier, primary text color `#e2e8f0`
- Role column: 25% width — role name or "—" in `#94a3b8` if null
- Missing fields column: 20% width — chip group or empty cell
- Edit column: 15% width, right-aligned — "Edit person" link in `#93c5fd` underline, 14px/400

**IncompleteToggle** (`/admin/people` — top of page, above table)
- CSS-only toggle switch; no JS library
- Track: `width: 44px; height: 24px; border-radius: 12px; border: 1px solid #334155; background-color: #0f1117;` (off state)
- Track active: `background-color: rgba(147,197,253,0.2); border-color: #93c5fd;` (on state)
- Thumb: `width: 18px; height: 18px; border-radius: 50%; background-color: #94a3b8; transform: translateX(2px);` (off)
- Thumb active: `background-color: #93c5fd; transform: translateX(22px);` (on)
- Implementation: `<input type="checkbox">` hidden + `<label>` with CSS pseudo-elements; or native `<input type="checkbox" role="switch">` with custom styling
- Label text: "Show incomplete only" — 14px/400/`#94a3b8`, inline beside toggle
- Toggle container: `display: flex; align-items: center; gap: 8px; margin-bottom: 16px;`
- aria: `role="switch"` + `aria-checked` state on the checkbox

**MissingFieldChip**
- Inline `<span>` element
- Style: `display: inline-block; background-color: rgba(245,158,11,0.15); border: 1px solid #f59e0b; color: #f59e0b; border-radius: 4px; padding: 4px 8px; font-size: 14px; font-weight: 400; line-height: 1.4;`
- Values: "bio", "photo", "role" — derived server-side; `missing: string[]` field on PersonListItem response
- Chip group: `display: flex; gap: 4px; flex-wrap: wrap;`
- Empty cell: no chips — cell is empty, not "—"

**PersonEditForm** (`/admin/people/[id]`)
- Single scrolling page with three visually separated sections; one Save button at the bottom
- Form container: `max-width: 640px; margin: 0 auto;` — narrower than the 860px pipeline pages; form-heavy content benefits from tighter line length
- Section card: `background-color: #1e293b; border: 1px solid #334155; border-radius: 8px; padding: 24px; margin-bottom: 24px;`
- Section heading: `font-size: 20px; font-weight: 600; color: #e2e8f0; margin: 0 0 16px 0; line-height: 1.2;`
- Section divider between sections: `margin-bottom: 24px` gap (no explicit `<hr>` — card borders create visual separation)

**FormInput** (reusable input pattern — same as Phase 7)
- Label: `display: block; font-size: 14px; font-weight: 400; color: #94a3b8; margin-bottom: 8px;`
- Input: `display: block; width: 100%; background-color: #0f1117; border: 1px solid #334155; border-radius: 6px; padding: 8px 12px; font-size: 16px; color: #e2e8f0; box-sizing: border-box;`
- Focus ring: inherited from global `*:focus-visible` rule — do not add custom outline

**FormTextarea** (bio_text field)
- Same styling as FormInput but `<textarea>`: add `min-height: 120px; resize: vertical; font-family: inherit;`
- No max-height constraint — operator sets content length

**RoleSelect** (role dropdown on edit form)
- `<select>` element: `display: block; width: 100%; background-color: #0f1117; border: 1px solid #334155; border-radius: 6px; padding: 8px 12px; font-size: 16px; color: #e2e8f0; box-sizing: border-box;`
- Last `<option>`: "＋ Add new role" (fullwidth plus sign for visual distinction from person names)
- Selecting "＋ Add new role" reveals AddRoleInlineForm below the select (not a modal)
- `<option>` values: role ids; displayed text: role names

**AddRoleInlineForm** (appears below RoleSelect when "＋ Add new role" selected)
- Container: `margin-top: 8px; padding: 12px; background-color: #0f1117; border: 1px solid #334155; border-radius: 6px;`
- Single text input: "Role name" label + input (same FormInput styling)
- "Create role" button: `font-size: 14px; font-weight: 600; color: #e2e8f0; background: transparent; border: 1px solid #93c5fd; border-radius: 6px; padding: 8px 16px; min-height: 36px; margin-top: 8px; cursor: pointer;`
- On success: form collapses, new role appears selected in the RoleSelect dropdown
- On error: inline error paragraph `role="alert"` below button

**TenureRowList** (Court Tenure section in PersonEditForm)
- Each row: `display: flex; gap: 16px; align-items: flex-start; margin-bottom: 16px;`
- Three inputs per row: Seat (text input, 40% flex), Start date (`type="date"`, 25% flex), End date (`type="date"`, 25% flex)
- Trash icon button per row: 10% flex, `color: #ef4444; background: transparent; border: none; cursor: pointer; font-size: 18px; min-height: 32px; padding: 4px 8px; align-self: flex-end;` — Unicode `✕` or `🗑` glyph; no image dependency
- "Add tenure" button: `display: block; width: 100%; margin-top: 8px; font-size: 14px; font-weight: 400; color: #94a3b8; background: transparent; border: 1px solid #334155; border-radius: 6px; padding: 8px 16px; min-height: 44px; cursor: pointer; text-align: center;`
- Client-side state via `$state<TenureRow[]>` — add/delete rows before submit; all rows sent together on Save

**SaveChangesButton** (bottom of PersonEditForm)
- Full-width, 44px min-height — primary CTA
- Style: `display: block; width: 100%; min-height: 44px; background: transparent; border: 1px solid #93c5fd; border-radius: 6px; font-size: 16px; font-weight: 600; color: #e2e8f0; cursor: pointer; margin-top: 8px;`
- Submitting state: text becomes "Saving…"; `disabled` attribute set; `opacity: 0.7`

**ParticipantList** (addition to `/admin/pipeline/[job_id]` page — below existing step cards)
- Only rendered when `job.status === 'completed'` and `participants.length > 0`
- Container: `margin-top: 32px; background-color: #1e293b; border: 1px solid #334155; border-radius: 8px; padding: 24px;`
- Section heading: `font-size: 20px; font-weight: 600; color: #e2e8f0; margin: 0 0 16px 0; line-height: 1.2;` — content: "{N} resolved participant{s}" (e.g., "3 resolved participants")
- List: `<ul style="list-style: none; padding: 0; margin: 0 0 16px 0;">`
- Each item: `<li style="font-size: 16px; color: #e2e8f0; padding: 8px 0; border-bottom: 1px solid #334155;">`
  - Format: "{full_name}" + `<span style="color: #94a3b8; font-size: 14px; margin-left: 8px;">({role_name})</span>`
  - Last item: no border-bottom
- "Review people" link: `<a>` styled as button — `display: inline-block; font-size: 14px; font-weight: 400; color: #93c5fd; border: 1px solid #334155; border-radius: 6px; padding: 8px 16px; text-decoration: none;`
- Link destination: `/admin/people?incomplete=1`

## Interaction States

### `/admin/people` — Directory

| State | Trigger | UI Response |
|-------|---------|------------|
| Default load | Page load, no query param | Toggle unchecked; full people list renders |
| Incomplete filter on | Click toggle or navigate with `?incomplete=1` | SvelteKit navigation appends/removes `?incomplete=1`; load fn re-runs; table re-renders filtered list; toggle pre-checked |
| Incomplete filter off | Click toggle when active | Navigate to `/admin/people` (no query param); full list re-renders |
| Empty — no people | People table is empty (no records) | "No people yet" empty state card rendered in place of table |
| Empty — filtered | Filter active, no incomplete records | "No incomplete records" empty state card rendered |

### `/admin/people/[id]` — Edit Form

| State | Trigger | UI Response |
|-------|---------|------------|
| Default load | Page load | Form pre-filled with current person data; tenure rows rendered from DB; role dropdown populated |
| Add tenure row | Click "Add tenure" | New empty tenure row appended to `$state` array; renders immediately; no server call |
| Delete tenure row | Click trash button on a row | Row removed from `$state` array; re-renders immediately; no server call |
| Select "＋ Add new role" | RoleSelect change event | AddRoleInlineForm appears below the select |
| Create role | Submit AddRoleInlineForm | `POST /api/admin/roles`; on success: new role added to select, selected automatically, inline form collapses |
| Create role — error | FastAPI 4xx | Inline error `role="alert"` in AddRoleInlineForm; form stays open |
| Save changes | Submit main form | Button text → "Saving…"; `disabled`; `use:enhance` sends PATCH; on success: redirect back to edit page with updated data |
| Save changes — error | FastAPI 4xx or validation | `role="alert"` error paragraph above save button; button re-enabled |

### `/admin/pipeline/[job_id]` — ParticipantList Addition

| State | Trigger | UI Response |
|-------|---------|------------|
| Job not completed | `status !== 'completed'` | ParticipantList section not rendered |
| Job completed, participants exist | `status === 'completed' AND participants.length > 0` | ParticipantList section renders below step cards |
| Job completed, no participants | `status === 'completed' AND participants.length === 0` | ParticipantList section not rendered (edge case: job with no resolved participants) |
| Click "Review people →" | Link click | Navigate to `/admin/people?incomplete=1` (standard `<a>` tag) |

## Accessibility Contract

Carried forward from Phase 7 with additions for new components.

| Requirement | Implementation |
|-------------|---------------|
| Touch targets | All primary buttons: `min-height: 44px` (WCAG 2.5.5); "Add tenure" button: 44px; Save changes: 44px |
| Focus ring | Global `*:focus-visible` in `app.css` — `outline: 2px solid #93c5fd` — do not override |
| Toggle switch semantics | `role="switch"` + `aria-checked` on the checkbox element |
| Table structure | `<table>` with `<thead>`, `<tbody>`, `<th scope="col">` for directory table |
| Error announcement | Error paragraphs: `role="alert"` (established Phase 6 pattern) |
| Disabled controls | "Save changes" in submitting state: `disabled` attribute set (not just visual opacity) |
| Tenure delete button | `aria-label="Remove tenure row"` on trash button — glyph alone is not sufficient |
| Breadcrumb link | Plain `<a>` with screen-reader visible text "← People" |
| Date inputs | `<input type="date">` — browser-native date picker; `aria-label` set if `<label>` is not adjacent |
| Add role inline form | `aria-expanded` on the role select to signal form is shown/hidden |
| Participant list | `<ul>` with `<li>` items — not a `<table>` (ordered list, no column structure) |
| Missing field chips | `<span>` elements within a parent `<span aria-label="Missing: bio, photo">` for screen reader summary |
