## Milestone Summary

**Key Decisions:**
- Migration 0006 adds six nullable columns to people (D-01); full_name NOT NULL preserved as resolution anchor (D-02); no backfill (D-03)
- _derive_full_name requires BOTH first_name AND last_name non-empty — prevents anchor corruption
- TopNav accepts variant prop; each layout passes its own value — component stays URL-unaware (D-03/D-04)
- Migration 0007 adds nullable published_at to arguments; resolved_at unchanged; get_cases() public gate swapped to published_at
- ArgumentUpdate allow-list is exactly {case_name, docket_number, argued_date} — published_at never PATCH-writable
- merge_people uses single async with db.begin() — no inner db.commit() (D-10, T-12-ATOMIC)
- upload_photo_to_spaces mirrors upload_pdf_to_spaces with caller-supplied content_type
- lastKnownStep $state tracks last non-null current_step; passed as fallback to stepStatus only when status=running and current_step=null (PIPE-18)
- Custom Svelte 5 Runes combobox replaces native datalist — no new dependency; per-row state in RowState interface (PIPE-19)
- SpeakerPopoverEntry uses list[TenureEntry] not ORM relationship — avoids N+1 lazy loads
- appointing_president_party excluded at schema and service layers (T-14-02, apolitical framing)
- bits-ui ^2.18.1 chosen for speaker popover — only Svelte 5-native headless popover after @skeletonlabs/floating-ui-svelte archived Oct 2025

**Issues Resolved:**
- People schema extended with structured name parts and appointing president/party (PEOP-01, PEOP-02)
- Public visibility gate migrated from resolved_at to published_at (allows metadata editing before publish)
- Speaker alias typeahead replaced with custom Svelte 5 Runes combobox (PIPE-19)
- Photo upload, person delete, and person merge added to admin people directory

**Issues Deferred:**
- PUB-04: Keyboard accessibility / Escape key for speaker popover — not formally verified in v1.2
- Phase 11 VERIFICATION.md human_needed status — acknowledged at v1.3 close (2026-06-29)
