## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator browser → SvelteKit form actions | Operator-entered title/docket/date and publish intents |
| SvelteKit server → FastAPI | X-Admin-Token attached server-side; FASTAPI_BASE_URL is server-only |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-ENV | Information Disclosure | FASTAPI_BASE_URL / ADMIN_TOKEN | mitigate | Imported only from `$env/static/private` in +page.server.ts; never PUBLIC_, never reaches the client bundle (project rule, Phase 9 pattern) |
| T-11-PUBUI | Tampering | publish/unpublish form actions | mitigate | UI only renders the Publish control when state allows; the authoritative guard is server-side in publish_argument (Plan 02 T-11-PUBGATE) — UI gating is defense-in-depth, not the control |
| T-11-XSS | Tampering | rendering case_name / docket in tables/headings | mitigate | Svelte escapes interpolated text by default; no `{@html}` used for argument fields |
| T-11-SC | Tampering | npm/pip/cargo installs | accept | No package installs in this phase (RESEARCH.md — no new npm packages) |
</threat_model>
