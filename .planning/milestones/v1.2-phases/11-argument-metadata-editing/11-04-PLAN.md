<objective>
Extend the existing job detail page (`/admin/pipeline/[job_id]`) with an argument metadata preview card and a "Ready to publish" call-to-action (D-03, D-04). The load function gains a separate fetch to `GET /api/admin/arguments/{argument_id}` (when `argument_id` is set) — not an expansion of AdminJobResponse, which would bloat the jobs list endpoint (RESEARCH Pattern 5 / Anti-Pattern). The Svelte page renders the preview above the step timeline and, when the job is completed but the argument is unpublished, a CTA guiding the operator to the editor.

Purpose: Closes the operator's loop — after the pipeline completes, the operator is guided directly to publish the argument rather than having to know to navigate to /admin/arguments. Supports ARG-01 by surfacing the editable metadata from the pipeline flow.
Output: Two extended files in the existing job detail route.
</objective>
