# Phase 12 Plan 05: Gap Fix — Photo URL Fetch + Alias-Safe Delete

## Source Gaps

- **Gap A (UAT test 3):** Submitting a photo URL stores the external URL string in the database instead of fetching the image and saving it locally. All photo storage should be self-contained.
- **Gap B (UAT test 8):** A person with only aliases (and no utterances/appearances/argument_participants) cannot be deleted. Aliases are name variants intrinsic to the person and should not block deletion.

## Gap A Root Cause — Photo URL stores external reference

In `api/routers/admin.py` `upload_person_photo`: the `elif photo_url is not None` branch calls `people_service.update_photo_url(db, person_id, photo_url)`, which writes the URL string directly to `person.photo_url` without fetching the image. The fix: fetch the image bytes with httpx, validate with Pillow (same two-gate check as the file-upload path), then call `people_service.upload_photo()` to save via the existing dual-path local/Spaces logic.

## Gap B Root Cause — Aliases block orphan check

In `api/services/admin_people.py` `delete_person_if_orphan`: `SpeakerAlias` is included in the FK orphan-check loop. Any alias count > 0 returns `False`, causing the caller to return 409. Aliases are intrinsic to the person (name variants) — they should be deleted with the person, not block deletion. Fix: delete all `SpeakerAlias` rows for the person before the orphan check, then only check `Utterance`, `CaseAppearance`, and `ArgumentParticipant`.

## Tasks

### Task 1 — Fix photo URL path: fetch, validate, save locally

**File:** `api/routers/admin.py`

1. Add `import httpx` to the module-level imports (alphabetically after `import hmac`).

2. In `upload_person_photo`, replace the `elif photo_url is not None:` branch (currently one line: `result = await people_service.update_photo_url(db, person_id, photo_url)`) with:

```python
elif photo_url is not None:
    try:
        async with httpx.AsyncClient(timeout=10.0) as client:
            r = await client.get(photo_url, follow_redirects=True)
            r.raise_for_status()
            file_bytes = r.content
    except Exception:
        raise HTTPException(status_code=422, detail="Could not fetch image from URL.")
    # Same two-gate Pillow check as the file-upload path (Pitfall 2: read format before verify)
    try:
        with Image.open(BytesIO(file_bytes)) as img:
            img_format = img.format
            img.verify()
    except (UnidentifiedImageError, Exception):
        raise HTTPException(status_code=422, detail="URL does not point to a valid image.")
    ext_map = {"JPEG": "jpg", "PNG": "png", "WEBP": "webp"}
    ext = ext_map.get(img_format or "", "jpg")
    content_type = f"image/{ext}"
    result = await people_service.upload_photo(db, person_id, file_bytes, ext, content_type)
```

Commit: `fix(12-05): fetch and save photo from URL instead of storing external reference`

### Task 2 — Fix delete: delete aliases before orphan check
