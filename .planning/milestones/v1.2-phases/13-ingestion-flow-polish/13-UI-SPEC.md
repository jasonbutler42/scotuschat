# Phase 13 — UI Design Contract

> Visual and interaction contract for Phase 13: Ingestion Flow Polish.
> Generated by gsd-ui-researcher. Verified by gsd-ui-checker.
>
> This phase touches three areas of the existing admin pipeline UI:
> 1. Step status badge correctness during null `current_step` transitions (PIPE-18)
> 2. Custom combobox replacing native `<datalist>` for speaker alias typeahead (PIPE-19)

## Component Inventory

New and modified UI elements for Phase 13. All are inline-styled Svelte markup — no external component imports.

### 1. StepStatus fallback (PIPE-18) — Modified behavior, no new visual element

- Tracking variable: `let lastKnownStep = $state<string | null>(data.job.current_step ?? null)` — declared outside the `$effect` poll loop
- Update: inside the poll loop after `invalidateAll()`, if `data.job.current_step !== null`, assign `lastKnownStep = data.job.current_step`
- `stepStatus()` call site: pass `lastKnownStep ?? data.job.current_step` instead of reading `job.current_step` directly, so null mid-transition falls back to the last known step
- Poll interval: change `setInterval` delay from `2500` to `1000` when `job.status === 'running'`; terminal-state short-circuit stays unchanged
- No visual change: badge colors, glyphs, card border stripes are identical

### 2. Combobox (PIPE-19) — Replaces `<input list> + <datalist>` in `{:else if s?.correcting}` branch

Location: `app/src/routes/admin/pipeline/[job_id]/+page.svelte` — `{:else if s?.correcting}` block (~line 515)

Structure:
```
<div> (relative, contains input + dropdown)
  <input type="text" ...>      ← text input, always visible when correcting
  {#if dropdownOpen && filteredCandidates.length > 0}
    <ul role="listbox" ...>    ← absolute, below input
      {#each filteredCandidates}
        <li role="option" ...> ← candidate row
      {/each}
      <li role="option" ...>   ← "Add new person" — always last
    </ul>
  {/if}
</div>
```

Input styles (matches existing typeahead input exactly):
- `background-color: #0f1117`
- `border: 1px solid #93c5fd` (accent — signals active correction mode)
- `border-radius: 6px`
- `padding: 6px 10px`
- `font-size: 16px`
- `color: #e2e8f0`
- `width: 100%`

Dropdown `<ul>` styles:
- `position: absolute`
- `top: 100%` (flush below input)
- `left: 0`
- `width: 100%` (matches input width)
- `margin-top: 4px`
- `background-color: #1e293b`
- `border: 1px solid #334155`
- `border-radius: 6px`
- `padding: 4px 0`
- `max-height: 240px`
- `overflow-y: auto`
- `z-index: 10`
- `list-style: none`
- `margin: 0`

Candidate `<li>` styles (default):
- `padding: 8px 12px`
- `font-size: 16px`
- `color: #e2e8f0`
- `cursor: pointer`
- `background-color: #1e293b`

Candidate `<li>` styles (hover/keyboard focus):
- `background-color: #334155`

"Add new person" `<li>` styles:
- Same structure as candidate `<li>` but `color: #93c5fd` (accent blue) and `font-size: 14px`
- Text: "Add new person" (plain, no em dash prefix)

Combobox open/close rules:
- **Open**: when input receives focus AND `query.length > 0`, OR when input receives focus and there are pre-existing candidates (always show on focus)
- **Close on selection**: clicking a candidate or pressing Enter on the keyboard-focused item closes the dropdown and calls `handleSelectPerson(rowKey, id)`
- **Close on Escape**: clears the input query and restores it to the empty state; does NOT restore the previous selection (fresh start)
- **Close on outside click**: `document.addEventListener('click', handler)` in `$effect` cleanup; checks `!container.contains(event.target)`
- Clicking outside with no selection made: `s.correcting` remains `true` but dropdown is hidden; operator must re-focus to reopen

Filter logic:
- `let query = $state('')`
- `let filteredCandidates = $derived(candidates.filter(c => { const text = c.role_name ? c.full_name + ' ' + c.role_name : c.full_name; return text.toLowerCase().includes(query.toLowerCase()); }))`
- Match on combined `full_name + role_name` string, case-insensitive contains — per CONTEXT.md D-06
- "Add new person" item always shown at the bottom regardless of query (per D-07)

Accessibility:
- Input: `role="combobox"`, `aria-expanded={dropdownOpen}`, `aria-haspopup="listbox"`, `aria-label="Search for speaker"`, `aria-autocomplete="list"`
- Dropdown `<ul>`: `role="listbox"`, `id` matching input's `aria-controls`
- Each `<li>`: `role="option"`, `aria-selected={false}` (single-select, selection committed on click)
- Keyboard: Up/Down arrows move highlight through items, Enter selects, Escape clears and closes

### 3. Incomplete Filter Toggle (PIPE-20) — New element on `/admin/pipeline` list page

Location: `app/src/routes/admin/pipeline/+page.svelte` — above the "Recent Runs" `<h2>` heading

Pattern: Matches `/admin/people` incomplete toggle exactly (`role="switch"` pill button + `goto()`).

Toggle container:
- `display: flex; align-items: center; gap: 8px; margin-bottom: 16px;`

Toggle button (`<button role="switch" aria-checked={incomplete} aria-label="Show incomplete only">`):
- Width: 44px, height: 24px
- `border-radius: 12px`
- Off state border: `1px solid #334155`; off state bg: `#0f1117`
- On state border: `1px solid #93c5fd`; on state bg: `rgba(147,197,253,0.2)` (accent tint)
- Knob: 18px × 18px circle, `border-radius: 50%`
- Knob off color: `#94a3b8`; knob on color: `#93c5fd`
- Knob transition: `translateX(2px)` off → `translateX(22px)` on

Toggle label (`<span>`):
- Off: `font-size: 14px; font-weight: 400; color: #94a3b8;` — text: "Show incomplete only"
- On: `font-size: 14px; font-weight: 400; color: #e2e8f0;` — text: "Show incomplete only" (same text; color brightens)

Navigation behavior:
- Toggle off → `goto('/admin/pipeline')` (clears param)
- Toggle on → `goto('/admin/pipeline?incomplete=1')`

Server-side: load function reads `url.searchParams.get('incomplete') === '1'` and passes `incomplete: boolean` to the API call (`GET /api/admin/jobs?incomplete=true`).

Active state visual (when filter is on): The toggle label text brightens to `#e2e8f0` and the table rows shown are only `paused` + `failed` jobs.

Empty state when filter is on (no incomplete jobs):
- Show the existing empty state card layout (matches "No runs yet" card)
- Heading: "No jobs need attention"
- Body: "All recent runs completed or are running. Toggle off to see the full history."

## Interaction State Map

### Combobox states

| State | Input border | Dropdown | Input value |
|-------|-------------|----------|-------------|
| Idle (not correcting) | — | hidden | — |
| Correcting, empty query | `#93c5fd` | visible (all candidates shown) | "" |
| Correcting, query typed | `#93c5fd` | visible (filtered) | query string |
| Candidate hovered | `#93c5fd` | visible, item bg `#334155` | query string unchanged |
| Candidate selected | `#93c5fd` | hidden | selected name |
| Escape pressed | `#334155` | hidden | cleared |
| Outside click | `#93c5fd` | hidden | query string preserved |

### Step badge states during null `current_step` transition (PIPE-18)

| Condition | Badge behavior |
|-----------|---------------|
| `job.status === 'running'` AND `current_step !== null` | Normal: badge for `current_step` shows "Running" |
| `job.status === 'running'` AND `current_step === null` | Fallback: use `lastKnownStep` — badge continues showing "Running" for that step |
| Poll returns non-null `current_step` after null period | `lastKnownStep` updates; display corrects immediately |

### Filter toggle states

| State | Toggle | Label color | Table content |
|-------|--------|-------------|---------------|
| Off (default) | pill left, `#94a3b8` knob | `#94a3b8` | All jobs |
| On (`?incomplete=1`) | pill right, `#93c5fd` knob | `#e2e8f0` | `paused` + `failed` only |

## Accessibility Contract

All carry forward from Phase 7 (T-07-13) and Phase 4 WCAG 2.1 AA. Phase 13 specific additions:

- **Combobox**: Full ARIA combobox pattern — `role="combobox"`, `aria-expanded`, `aria-haspopup="listbox"`, `aria-controls`, `aria-autocomplete="list"`. Listbox items use `role="option"`. Keyboard: Up/Down to navigate, Enter to select, Escape to close.
- **Incomplete toggle**: `role="switch"` + `aria-checked` — matches `/admin/people` pattern.
- **Step badge `aria-live`**: The `aria-live="polite"` wrapper on the step cards container is already in place — the null-step fix means no extra flicker of announcements during transitions.
- **Focus ring**: Global `*:focus-visible { outline: 2px solid #93c5fd; }` applies to combobox input and all interactive elements without modification.
- **Min touch target**: All buttons and interactive items ≥ 44px min-height (WCAG 2.5.5).
