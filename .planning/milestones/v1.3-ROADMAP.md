## Milestone Summary

**Key Decisions:**
- Migration 0008 commits Alembic transaction before ALTER TYPE ADD VALUE — PG forbids ADD VALUE inside a transaction block; this is the guard
- SideEnum.ADVOCATE retained as legacy member; backfilled to UNKNOWN — PG cannot drop enum values once added
- _tenure_role_name uses datetime.date objects (not strings) for comparison — avoids lexicographic sort bugs on ISO strings with null values
- D-14 fallback: argued_date outside all tenure windows → use highest start_date seat (most recent tenure wins)
- argued_date=None fallback: use most-recent tenure (Pitfall 5 guard in speakers.py)
- cover_extractor.py module is self-contained; HEADER_RE/PAGE_NUM_RE/strip_line_number imported from extractor.py (not redefined)
- Both cover extraction UPDATE blocks placed after dry-run gate (line 234); CPU-only extraction runs before gate (Pitfall 1 guard — no synchronous I/O inside async DB session)
- ParseStats assembled from scalar COUNT results (no from_attributes); injected via job.__dict__ before model_validate reads ORM row
- PDF endpoint branches spaces_key FIRST per Pitfall 2; disk fallback reads PipelineRun.pdf_path from ingest run via get_run_id_for_step
- PDF proxy uses redirect:'manual' — pre-signed Spaces URL goes directly to the browser without transiting SvelteKit memory; ADMIN_TOKEN stays server-side
- formatDate() declared at script top-level (not inside {#if}/{@const}) — {#if}-scoped {@const} not accessible from sibling {#each} loops (Pitfall 5)
- participants each-key: participant_id (PK, always unique) not person_id (FK, can repeat across argument_participants for same argument)
