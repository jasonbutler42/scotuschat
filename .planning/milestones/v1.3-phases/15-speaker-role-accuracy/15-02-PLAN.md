## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Operator browser → admin API | Untrusted form/JSON input crosses into participant-side PATCH and approve/rerun POST; all routes behind verify_admin_token |
| Admin API → DB writes | Participant side, argument status, resolved_at mutations |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-15-02-IDOR | Tampering | PATCH /arguments/{id}/participants/{pid} | high | mitigate | update_participant_side WHERE scoped by BOTH argument_id and participant_id; router returns 404 on cross-argument mismatch (Pitfall 9) |
| T-15-02-MASS | Tampering | ParticipantSideUpdate body | high | mitigate | Schema exposes only `side: SideEnum`; no other ArgumentParticipant column is writable |
| T-15-02-BENCH | Tampering | participant side set to BENCH via PATCH | medium | mitigate | Service raises ValueError when side == BENCH → 422; BENCH is not operator-settable on advocates |
| T-15-02-RACE | Spoofing | double-approve race | medium | mitigate | approve_job validates argument.status == PIPELINE before write; second call → 422 (Pitfall 6) |
| T-15-02-AUTH | Elevation of Privilege | new admin endpoints | high | mitigate | Endpoints inherit router-level `Depends(verify_admin_token)`; no anonymous access |
| T-15-02-SC | Tampering | package installs | low | accept | No new packages — N/A per 15-RESEARCH Package Legitimacy Audit |
