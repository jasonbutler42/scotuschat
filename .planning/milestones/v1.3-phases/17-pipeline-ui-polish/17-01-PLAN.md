<objective>
Add the backend support for Phase 17 pipeline UI polish: store the original upload filename, compute parse stats at render time, and serve the source PDF through one unified admin endpoint.

Purpose: The pipeline job detail page needs (1) the source identifier, (2) utterance + speaker counts for the Parse card, and (3) a way to open the original PDF. All three are server-side concerns; the frontend (Plan 17-02) only renders what this plan exposes.
Output: Migration 0009 (`original_filename` column), extended `AdminJobResponse` (`original_filename`, `parse_stats`), parse-stats query in `get_job()`, a `generate_pdf_presigned_url` helper, and a new `GET /api/admin/jobs/{job_id}/pdf` route.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → SvelteKit | Operator browser; admin token never present client-side (token injected server-side only) |
| SvelteKit → FastAPI | `/api/admin/*` calls carry `X-Admin-Token`; FASTAPI_BASE_URL is server-only |
| FastAPI → DO Spaces | Pre-signed URL generated with server-held credentials |
| FastAPI → disk | `PipelineRun.pdf_path` read from DB row, never from request input |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-17-01 | Information disclosure | GET /jobs/{job_id}/pdf (IDOR) | high | mitigate | Route inherits router-level `verify_admin_token`; `job_id` typed `int` (FastAPI rejects non-int); no per-row authz needed (admin-only surface) |
| T-17-02 | Tampering | FileResponse path | high | mitigate | `pdf_path` read from the DB row written by the pipeline at ingest — never derived from a request parameter; no path traversal vector |

| T-17-04 | Spoofing | original_filename display | low | accept | Client-supplied at upload; display-only — never used as a file path or in any server-side file operation |

| T-17-SC | Tampering | npm/pip/cargo installs | n/a | accept | No new packages introduced this phase — RESEARCH Package Legitimacy Audit: not applicable |
