<architecture_note>
## PDF link routing — deviation from the literal PATTERNS/UI-SPEC anchor

17-PATTERNS.md and 17-UI-SPEC.md show the PDF link as a plain anchor pointing directly at the FastAPI endpoint: `href="/api/admin/jobs/{id}/pdf"`. That literal URL does NOT work in this project and MUST NOT be used as written:

- This project has NO Vite dev proxy and NO `/api` SvelteKit route (verified: `app/vite.config.ts` has no `server.proxy`; `app/src/routes/api` does not exist). The browser cannot reach FastAPI at `/api/...`.
- CLAUDE.md Architecture Rule 2: all FastAPI calls from SvelteKit go through server-side code; `FASTAPI_BASE_URL` is server-only, never `PUBLIC_`. A browser anchor to FastAPI would either 404 (no route) or leak the admin token.

The established analog is the Phase 12 same-origin proxy at `app/src/routes/admin/people/[id]/merge-preview/+server.ts`: a SvelteKit `+server.ts` route under `/admin/...`, auth-guarded by `hooks.server.ts`, that injects `ADMIN_TOKEN` and calls `FASTAPI_BASE_URL` server-side. Task 1 creates the equivalent PDF proxy; the anchor (Task 3) targets that same-origin SvelteKit URL. This satisfies UI-SPEC's "Always calls the unified backend endpoint … frontend never branches on storage mode" intent (the frontend still calls one URL) while honoring the actual routing architecture.
</architecture_note>

    Create app/src/routes/admin/pipeline/[job_id]/pdf/+server.ts exporting a `GET` `RequestHandler` (import the `RequestHandler` type from `./$types`). Import `ADMIN_TOKEN` and `FASTAPI_BASE_URL` from `$env/static/private` (server-only — never expose to the client, per CLAUDE.md Rule 2 and T-17-TOKENLEAK below). Import `error` from `@sveltejs/kit`.

    In the handler, call FastAPI server-side: `fetch(\`${FASTAPI_BASE_URL}/api/admin/jobs/${params.job_id}/pdf\`, { headers: { 'X-Admin-Token': ADMIN_TOKEN }, redirect: 'manual' })`. The `redirect: 'manual'` is REQUIRED so a FastAPI 302 (the Spaces pre-signed URL case from 17-01) is NOT followed server-side — instead the proxy passes a same-origin 302 back to the browser so the operator's browser navigates to the pre-signed Spaces URL directly (keeps the PDF bytes off the SvelteKit server and the address bar shows the expiring URL — acceptable per 17-RESEARCH Security Domain).

    Handle the two FastAPI response shapes:
    1. Redirect (`res.status === 302` or `res.status === 0` with `res.type === 'opaqueredirect'`): read the `Location` header (`res.headers.get('location')`). If present, return a new same-origin redirect to that URL using `new Response(null, { status: 302, headers: { Location: location } })`. Because `redirect: 'manual'` can produce an opaque response where the Location header is unreadable, ALSO handle the opaque case by re-fetching with `redirect: 'follow'` and streaming the body (see fallback below) — prefer streaming when Location is null.
    2. Streamed PDF (`res.ok`, disk-backed FileResponse): return a new `Response(res.body, { status: 200, headers: { 'Content-Type': res.headers.get('content-type') ?? 'application/pdf', 'Content-Disposition': res.headers.get('content-disposition') ?? 'inline' } })`. Forward `res.body` (a ReadableStream) directly — do not buffer the whole PDF into memory.

    On a non-OK, non-redirect FastAPI response (e.g. 404 job/PDF not found), call `error(res.status === 404 ? 404 : 502, 'Source PDF not available')`. Wrap the fetch in try/catch and `error(502, 'Source PDF not available')` on a thrown network error.

    Do NOT add any per-route auth check — hooks.server.ts already guards all /admin/* requests including +server.ts endpoints. Do NOT echo ADMIN_TOKEN into any response header or body.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → SvelteKit | Operator browser; ADMIN_TOKEN must never reach the client |
| SvelteKit (+server.ts) → FastAPI | Server-side fetch carries `X-Admin-Token`; `FASTAPI_BASE_URL` server-only |
| SvelteKit 302 → DO Spaces | Browser follows a same-origin 302 to a short-TTL pre-signed Spaces URL |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-17-TOKENLEAK | Information disclosure | pdf/+server.ts | high | mitigate | ADMIN_TOKEN imported only from `$env/static/private`; injected into the server-side fetch header; never written to a response header/body and never sent as `PUBLIC_` (CLAUDE.md Rule 2). The anchor targets the same-origin proxy, not FastAPI directly. |
| T-17-AUTHZ | Elevation of privilege | pdf/+server.ts | high | mitigate | Route lives under `/admin/*`; `hooks.server.ts` guards every /admin/* request (including +server.ts endpoints) and redirects unauthenticated sessions to /admin/login before the handler runs. |
| T-17-OPENREDIRECT | Tampering | pdf/+server.ts 302 passthrough | medium | mitigate | The `Location` value is sourced from FastAPI's own response (server-controlled pre-signed Spaces URL), never from a client-supplied query param — no attacker-controlled open-redirect vector. |
| T-17-PRESIGN | Information disclosure | Spaces pre-signed URL in address bar | low | accept | URL is visible to the operator only, admin-only flow, 15-minute TTL bounds exposure (inherited from 17-01 D-06). |
| T-17-XSS | Tampering | rendered original_filename / pdf_url | low | accept | Svelte auto-escapes interpolated text (`{...}`); filename/URL are rendered as text content, not as HTML or unsanitized href — no injection vector. |
| T-17-SC | Tampering | npm/pip/cargo installs | n/a | accept | No new packages introduced — RESEARCH Package Legitimacy Audit: not applicable. |
</threat_model>
