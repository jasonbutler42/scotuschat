## Milestone Summary

**Key Decisions:**

- `is_justice BOOLEAN NOT NULL DEFAULT FALSE` backfilled from court_tenures in migration 0010; None-guarded conditional write in update_person
- `(source_docket, question_number)` UNIQUE constraint on arguments; IntegrityError deduplication in ingest; pre-flight UI check before run start
- `cover_metadata` JSONB written unconditionally at parse; nullable fields auto-populated conditionally
- Polling via `$effect + setInterval + invalidateAll()` on list page, unconditional (any run started from other tabs must be detectable); 1s interval matching detail page
- `delete_argument` returns `bool | None`: True=deleted, False=published (409), None=not found (404); FK cascade order: Utterance → PipelineRun → ArgumentParticipant → CaseArgument → NULL AdminJob.argument_id → Argument
- `AdminSubNav` component + `TopNav variant=public` in admin layout; dead `variant=admin` branch removed from TopNav
- Root layout `/admin/*` exclusion guard left intact to prevent double TopNav render

**Issues Resolved:**

- Duplicate argument creation from re-running ingest on same source (PIPE-25)
- Operator had no way to delete mis-created arguments or pipeline runs without raw DB access (ADMIN-01, ADMIN-02)
- Admin nav had bespoke markup diverging from public nav style (NAV-02)
- Pipeline list page never refreshed job status without manual reload (PIPE-23)

**Technical Debt Incurred:**

- None significant — all plans complete with SUMMARY.md
