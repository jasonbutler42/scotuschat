| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-19-03-01 | Tampering | MetadataUpdate mass assignment | high | mitigate | MetadataUpdate schema explicitly restricts writable fields to {case_name, source_docket, argued_date} — same pattern as ArgumentUpdate (T-11-MASS) |
| T-19-03-02 | Elevation of Privilege | IDOR on PATCH /arguments/{id}/metadata | medium | mitigate | Service returns False when argument_id not found; router translates to 404 — prevents blind PATCH to nonexistent IDs |
| T-19-03-03 | Tampering | SQL injection via docket query param | low | accept | SQLAlchemy parameterized query; docket is a bind parameter never string-interpolated into SQL |
| T-19-03-04 | Spoofing | check-duplicate endpoint auth bypass | medium | mitigate | Auth inherited at router level via Depends(verify_admin_token) on all routes in this router — no per-route auth needed, no bypass possible |
| T-19-03-05 | Tampering | check-duplicate path parameter conflict | medium | mitigate | Literal route /arguments/check-duplicate registered BEFORE /arguments/{argument_id} — FastAPI resolves literal segments first |
</threat_model>
