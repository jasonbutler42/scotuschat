## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → SvelteKit +server.ts (check-duplicate proxy) | Same-origin GET; SvelteKit injects ADMIN_TOKEN server-side; browser never sees token |
| SvelteKit form action → FastAPI (saveMetadata) | Server-to-server; ADMIN_TOKEN in server action; browser sends form POST to same-origin only |
| Browser → SvelteKit form action (start form) | Standard SvelteKit form POST; docket field value is text — no execution, stored in DB as VARCHAR |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-19-04-01 | Information Disclosure | ADMIN_TOKEN in check-duplicate fetch | high | mitigate | Token read from $env/static/private in +server.ts only; browser fetch hits SvelteKit same-origin URL with no token; T-12-TOKENLEAK pattern per STATE.md |
| T-19-04-02 | Tampering | Preflight bypass → duplicate creation | medium | accept | DB UNIQUE constraint is the authoritative backstop (D-06); preflight is a UX convenience only; ingest handles IntegrityError gracefully (Plan 02 Task 2) |
| T-19-04-03 | Tampering | cover_metadata keys rendered as hint text | low | accept | cover_metadata is JSONB from pipeline-controlled extraction; values are strings from PDF cover — rendered as escaped text in Svelte (not innerHTML); no XSS vector |
