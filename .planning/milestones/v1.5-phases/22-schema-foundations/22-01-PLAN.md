| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-22-01 | Denial of Service | Migration 0012 upgrade on existing data | medium | mitigate | Backfill is a single set-based INSERT...SELECT (no per-row loop); enum ADD VALUE uses IF NOT EXISTS for idempotency so a partial/re-run upgrade does not error |
