## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Pill internal gap between text and remove button; hint row gap |
| sm | 8px | Label-to-input gap; pill list gap; button internal horizontal padding |
| md | 16px | Field-to-field vertical gap; form section padding; button row gap |

### 2. DocketPillInput.svelte (new shared component)

**File:** `app/src/lib/components/DocketPillInput.svelte` (new)
**Extracted from:** `app/src/lib/components/ArgumentDetailsCard.svelte` inline pill logic

**Props interface:**
```ts
interface DocketPillInputProps {
  initialValues?: string[];   // default: []
  name?: string;              // default: "docket[]"
  readonly?: boolean;         // default: false
}
```

**Visual spec:**
- Label row: `font-size: 14px; font-weight: 400; color: #94a3b8; margin-bottom: 8px`
- Instruction text below input: `font-size: 13px; font-weight: 400; color: #64748b; margin: 0 0 4px 0` — copy: "Type a docket number and press Enter to add it."
- Pill list container: `display: flex; flex-wrap: wrap; gap: 8px; margin-bottom: 8px`
- Pill span: `display: inline-flex; align-items: center; gap: 6px; background-color: #1e293b; border: 1px solid #334155; border-radius: 4px; padding: 4px 8px; font-size: 14px; font-weight: 400; color: #e2e8f0`
- Remove button: `min-width: 28px; min-height: 28px; background: transparent; border: none; cursor: pointer; font-size: 14px; color: #94a3b8` — hover: `color: #ef4444`; aria-label: `"Remove docket {pill}"`; content: `×`
- Docket text input: `width: 100%; background-color: #0f1117; border: 1px solid #334155; border-radius: 6px; padding: 8px 12px; font-size: 16px; color: #e2e8f0; box-sizing: border-box; font-family: inherit`
- Enter key: calls `addPill()` with `e.preventDefault()` (no form submission)
- Hidden inputs: one `<input type="hidden" name={name} value={pill}>` per pill (D-05 pattern)
- Component is fully self-contained — no `change` event emitted; server reads serialized form data

**Interaction states:**
- Empty pill list: pill list container not rendered (no empty div)
- `readonly=true`: input disabled; remove buttons hidden; hidden inputs still rendered

**Refactor:** `ArgumentDetailsCard.svelte` replaces its inline pill logic with `<DocketPillInput initialValues={savedValues.dockets} name="docket[]" {readonly} />`. Behavior must be identical post-refactor.

## Interaction Contract

### Docket Pill Input (DocketPillInput.svelte)

| Trigger | Behavior |
|---------|----------|
| Type in docket text input + press Enter | `e.preventDefault()`; trim value; if non-empty and not duplicate: add pill to `$state` array, clear input |
| Type in docket text input + press Enter (empty or duplicate value) | Silently reject — no error shown, input cleared |
| Click "×" remove button on pill | Remove that pill from `$state` array |
| Form submit | Hidden inputs serialize all current pills as `docket[]` multi-value form data |

### Preflight (multi-pill)

| Trigger | Behavior |
|---------|----------|
| Form submit with 1+ pills and `preflightCleared=false` | `e.preventDefault()`; call `check-duplicate` for each pill (sequential preferred for simplicity); if any match: set `duplicateWarning` with the specific matching docket |
| All pills clear preflight | Set `preflightCleared=true`; call `formEl.requestSubmit()` |
| "Cancel" in warning | Reset `duplicateWarning=null`, `preflightCleared=false` |
| "Start anyway" in warning | Set `preflightCleared=true`, `duplicateWarning=null`; call `formEl.requestSubmit()` |
| No docket pills present | Submit without preflight check |

### Runs Table

| Trigger | Behavior |
|---------|----------|
| Page load | `$effect` polls `invalidateAll()` every 1000ms (unconditional — existing pattern, unchanged) |
| Back/bfcache restore | `pageshow` event handler calls `invalidateAll()` (existing, unchanged) |
| "Show incomplete only" toggle | `goto('/admin/pipeline?incomplete=1')` or `goto('/admin/pipeline')` (existing, unchanged) |

### Accessibility

| Control | Requirement |
|---------|-------------|
| All inputs, buttons | `min-height: 44px` (WCAG 2.5.5); `*:focus-visible` → `outline: 2px solid #93c5fd` (global, via app.css) |
| Duplicate warning | `role="alert"` on container (existing) |
| Runs table | `aria-live="polite"` on wrapper div (existing) |
| Toggle | `role="switch"` + `aria-checked` (existing) |
| Pill remove buttons | `aria-label="Remove docket {pill}"` |
| Table headers | `scope="col"` (existing) |
