<objective>
Close the single confirmed Phase 26 UAT gap (Test 18): the Archived badge exists on the pipeline job detail page (RunStatusCard) but is missing on the pipeline list page (/admin/pipeline). The operator expected the same grey "Archived" badge on both surfaces.

Root cause is a missing data field, not a missing render branch: `list_jobs()` runs a plain `select(AdminJob)` with no join to Argument, and `AdminJobResponse` carries no signal indicating whether the linked argument has already been created. The list page therefore cannot know which runs are archived.

Purpose: bring the pipeline list badge to parity with RunStatusCard's `already_created` override so a settled/read-only run reads as "Archived" everywhere.
Output: a new `is_archived` field on `AdminJobResponse`, populated by `list_jobs()` via an outerjoin, and consumed by the list page's badge logic.
</objective>
