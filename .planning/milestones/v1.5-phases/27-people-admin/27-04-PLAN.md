## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → SvelteKit server load | `tab`/`missing`/`tenure_gaps` URL params (untrusted) forwarded to FastAPI |
| server load → FastAPI | server-only FASTAPI_BASE_URL; no secrets to the client |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-27-08 | Tampering | `missing`/`tab` URL params | medium | mitigate | Params are forwarded to FastAPI which allow-lists them (Plan 27-02); the SvelteKit page treats them as opaque strings and never interpolates them into HTML sinks (Svelte auto-escapes). |
| T-27-09 | Information Disclosure | FASTAPI_BASE_URL / admin token | high | mitigate | All API calls stay in +page.server.ts; no `PUBLIC_` env leak to the client bundle (CLAUDE.md architecture rule 2). |
| T-27-SC | Tampering | npm/pip/cargo installs | high | accept | No new dependencies installed in this plan. |
</threat_model>
