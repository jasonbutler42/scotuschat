<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser form → SvelteKit save action | full_name/name parts/birthdate/tenures JSON/is_justice (untrusted) |
| save action → FastAPI PATCH | forwarded as JSON to /people/{id} behind admin auth |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-27-10 | Tampering | disabled Death Date / Reason Left inputs | medium | mitigate | Disabled inputs submit no form value AND the backend schema declares no death_date/reason_ended field (Plan 27-01/27-03), so even a hand-crafted POST cannot persist them — no silent-drop illusion (D-19). |
| T-27-11 | Tampering | tenures JSON hidden field | medium | mitigate | Server re-parses JSON and maps only the allow-listed keys (seat/start_date/end_date/appointed_by/appointing_president_party) into TenureRow; dates parsed via fromisoformat (ValueError→422); no extra keys reach the ORM. |
| T-27-12 | Cross-Site Scripting | free-text appointment/name/bio fields | medium | mitigate | Svelte auto-escapes all interpolated text; no `{@html}` sink is introduced. |
| T-27-SC | Tampering | npm/pip/cargo installs | high | accept | No new dependencies (`slide` is built into `svelte/transition`). |
</threat_model>
