## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-27-13 | Spoofing / Broken Auth | create action → POST /people | high | mitigate | The SvelteKit action attaches the server-only `X-Admin-Token` and the FastAPI route enforces the same admin-auth dependency (Plan 27-03); no anonymous path from the browser to person creation. |
| T-27-07 | Denial of Service | repeated create submissions (junk records) | low | accept | Admin-only surface behind auth; created records are mergeable/deletable via existing tools. Residual risk within the existing admin trust boundary. |
| T-27-14 | Information Disclosure | admin token exposure | high | mitigate | Token used only in +page.server.ts; never shipped to the client bundle (CLAUDE.md rule 2). |
| T-27-SC | Tampering | npm/pip/cargo installs | high | accept | No new dependencies installed in this plan. |
</threat_model>
