## Spacing Scale

Declared values (must be multiples of 4) — reusing the exact tokens already live in the codebase, per DESIGN-SYSTEM.md:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Gap between status-count badges/dots within a stat card row |
| sm | 8px | Label-to-value gap; gap between inline "View all" link and its row |
| md | 16px | Margin between stacked Needs Attention rows; margin between stat cards and the page header |
| lg | 24px | Card internal padding (`padding: 24px` — matches every existing card); heading-to-content margin |
| xl | 32px | NEW this phase — gap between grid items in the stat-card row and between the Needs Attention section and the stat-card grid below it (D-09 requires visible separation between the two page sections) |
| 2xl | 48px | Page content top/bottom padding (`<main>` wrapper, matches every other admin page) |
| 3xl | 64px | Not used this phase |

Exceptions: none. Touch targets for every clickable stat-card CTA and "View all" link are `min-height: 44px` (WCAG 2.1 AA), matching the existing site-wide convention — these are real full-size links, not compact table row actions, so the 36px compact exception does not apply here.

## Typography

Reuses the 3 existing sizes plus one new size introduced specifically for stat-card primary numbers (still within the "3-4 sizes, 2 weights" ceiling):

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 | 1.5 |
| Label | 14px | 400 | 1.4 (inline chips/status labels) or 1.5 (paragraph-style meta text) |
| Heading | 20px | 600 | 1.2 |
| Display | 32px | 600 | 1.2 — NEW this phase; used ONLY for each stat card's primary count number (the large "Total" figure). This is the one new visual element introduced by this phase to satisfy DASH-05's "visual hierarchy," since no existing admin card previously needed a large-emphasis numeral. Per-status breakdown sub-counts (Published/Draft/Unpublished, etc.) use Body (16px/400), not Display — only the single headline total per card gets the large treatment. |

Only two weights appear anywhere: 400 (regular) and 600 (semibold) — matches the existing project-wide convention exactly; no new weight introduced.

## Layout & Component Notes

*(Supplementary to the template above — for planner/executor use; not a checker dimension.)*

**Page order (D-09, locked):** Needs Attention section first, full-width. Stat card grid below it (Arguments / People / Utterances / Pipeline runs — 4 cards, equal width, `xl` (32px) gap). Web Traffic placeholder card in its own row below the stat grid, visually separated by a `2xl` (48px) top margin, `border: 1px dashed #334155`, `opacity: 0.7` — never sharing a grid row with the 4 real stat cards (D-12).

**New shared component:** `app/src/lib/components/StatCard.svelte` — first shared card component in the codebase (RESEARCH.md Pattern 2). Props: `title` (string) + a `children` snippet for the card body, so each card's differently-shaped breakdown (Arguments' 3 sub-links vs. Utterances' single number) is composed by the caller. Uses the exact existing card CSS (`background-color: #1e293b; border: 1px solid #334155; border-radius: 8px; padding: 24px;`) — Svelte 5 runes only (`$props`), no legacy `export let`.

**Needs Attention row shape:** each row shows the person/justice/argument's identifying label (name or case name) in Body size, plus context (missing-field count, "Missing tenure", or docket) in Label/muted size — capped at 5 rows per sub-list (D-01), with the "View all →" link appearing once per sub-list, after the last row (or in place of rows when empty).

**Combined vs. split People sub-list:** one combined "People" sub-list spanning both Bench and Advocate tabs (per CONTEXT.md's recommended resolution of its own open discretion note) — not split into two separate sub-lists.

**"Recent" pipeline window:** 30-day count window for the Pipeline runs stat card's primary number, with `last_activity_at` always shown unbounded by that window (per RESEARCH.md recommendation) — e.g. card shows `{n} runs (last 30 days)` as the Display-size number, with `Last activity: {date}` below it in Label size.

**Utterances scope:** total counts ALL utterance rows regardless of parent argument status (draft/published/unpublished/pipeline) — literal reading of DASH-01, per RESEARCH.md Assumption A3.
