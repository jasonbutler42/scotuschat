<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| PDF-derived displayed data to clipboard | Operator-visible strings cross into the clipboard only through explicit activation of the shared control |
| Route/component data to DOM | Extracted strings remain escaped Svelte text and are not interpreted as markup |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-36-05 | Tampering | Pipeline formatted values | high | mitigate | Compute the final displayed date/string once at the caller boundary and pass that same string to the shared control |
| T-36-06 | Spoofing | Cross-surface feedback | medium | mitigate | Reuse the component-local state machine; do not add a shared toast/store that can misattribute a copy result |
| T-36-07 | Information Disclosure | Route error handling | low | mitigate | Keep fixed local error copy and never expose clipboard exceptions or add network reporting |
| T-36-08 | Elevation of Privilege | Browser capability | low | mitigate | Clipboard writes occur only from native user activation; no mount-time, SSR, or automatic writes |
| T-36-SC | Tampering | npm installs | high | mitigate | Install nothing; if an executor proposes a package, stop for slopcheck and blocking human review of assumed or suspicious dependency output |
</threat_model>
