# Phase 36 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | Existing manual Svelte/Tailwind design system; no shadcn |
| Preset | Not applicable |
| Component library | Bits UI is installed, but no Bits UI primitive is required for this inline affordance |
| Icon library | None; use a simple 16px inline copy SVG with `aria-hidden="true"` |
| Font | `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif` |

This phase introduces one reusable `CopyableExtractedValue`-style Svelte abstraction rather than page-specific buttons. The name and file boundary are implementation discretion, but all sites must consume the same state machine, semantics, icon, and styling. Do not add a third-party tooltip, clipboard, or icon dependency.

## Component Contract

### Anatomy

1. Preserve the existing field label or `Extracted:` prefix outside the control.
2. Render the visible value and trailing copy icon as one native `button type="button"` target.
3. Place the 16px icon immediately after the value with an 4px gap; never place the icon in a separate target.
4. For docket collections, render one button per docket pill. Each button copies only its own displayed docket.
5. Preserve `N/A` in the same layout slot using a disabled button so the page does not reflow.

### States and interaction

| State | Visual contract | Accessible/behavior contract |
|-------|-----------------|------------------------------|
| Rest | Value uses the surrounding readout's existing typography; icon and text inherit the same color; transparent background and no added border except the existing docket-pill border | Accessible name is field-specific: `Copy docket`, `Copy question number`, `Copy argued date`, `Copy case name`, or `Copy title` |
| Hover | Text/icon change to accent `#93c5fd`; pointer cursor; docket pill border may also change to accent | Native `title` text matches the accessible name; no generic `Copy value` label |
| Keyboard focus | Same accent treatment as hover | Global 2px `#93c5fd` focus-visible outline with 3px offset remains visible and must not be overridden |
| Pressed | No layout shift; optional opacity reduction to 0.8 while the clipboard promise resolves | Copy exactly the rendered text, not the raw source value |
| Success | Replace the icon/field action label with `Copied` in success green `#4ade80` for 1,500ms | Announce `Copied` through a local `aria-live="polite"` region; repeated activation recopies and restarts the full 1,500ms timer |
| Failure | Keep the value visible and show `Couldn't copy.` locally in `#ef4444`; do not toast | Local message uses `role="alert"`; a later successful click clears the error and enters success state |
| Disabled | Keep `N/A` visible in italic muted `#94a3b8`; copy icon is muted; no hover accent; default/not-allowed cursor rather than pointer | Native `disabled`, absent from tab order; `title="Nothing extracted to copy."`; no clipboard call |

The clickable inline control must have a minimum 36px height and at least 8px horizontal padding around its contents. Where the existing docket pill is 24px high, enlarge the interactive target to 36px while preserving its compact pill appearance through internal alignment. Do not force 44px height into dense extracted-hint rows; the 36px exception matches established compact admin controls while remaining generous relative to the current plain text.

Use `navigator.clipboard.writeText(displayValue)`. Treat rejected promises or unavailable clipboard access as the local failure state. Clear all pending timers when the component is destroyed, and clear/restart the active timer for repeated clicks.

### Scope inventory

Apply the reusable pattern to extracted values that feed an operator-editable destination:

| Surface | Included extracted displays | Notes |
|---------|----------------------------|-------|
| `ArgumentDetailsCard.svelte` on argument editor and pipeline job detail | Each docket hint, question number hint, argued date hint | Individual docket buttons; retain `Extracted:` prefix and visible disabled `N/A` |
| Pipeline job detail parsed-output readouts | Case name, argued date, each docket, question number | Copy the formatted date exactly as rendered; do not attach copy to utterance/bench/advocate/total counts because they have no operator-editable destination |
| `ResolveCard.svelte` | Title hint for editable resolve rows | Include only where the adjacent title can be edited |
| Argument editor speaker rows | Title hint | Same copy and disabled states as ResolveCard |

Read-only extracted readouts without an operator-editable destination are intentionally excluded. This makes D-13 operational: future extracted fields receive this control by default only when an operator-editable destination exists, unless their phase explicitly opts out.

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Value-to-icon gap, hint-row top margin |
| sm | 8px | Horizontal target padding, compact gaps |
| md | 16px | Default field spacing |
| lg | 24px | Existing card padding and section spacing |
| xl | 32px | Layout gaps |
| 2xl | 48px | Existing page content top/bottom padding |
| 3xl | 64px | Page-level spacing when needed |

Exceptions: 36px minimum inline target height for dense extracted readouts; existing global focus outline is 2px with a 3px offset. These exception dimensions are not spacing tokens.

## Typography

Use exactly the existing four-size/two-weight admin scale:

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Compact pill/status | 12px | 400 | 1.5 |
| Label, hint, feedback | 14px | 400 | 1.5 |
| Value/control body | 16px | 400 | 1.5 |
| Card/page heading | 20px | 600 | 1.2 |

`Copied` and `Couldn't copy.` use 14px/400. The copy button inherits the size of the existing value: 12px in docket pills and 14px or 16px in other readouts. Do not introduce bold copy affordances or a third font weight.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0f1117` | Page background, inset input/pill background |
| Secondary (30%) | `#1e293b` with `#334155` borders | Cards, navigation, control surfaces, default pill borders |
| Accent (10%) | `#93c5fd` | Copy hover/focus treatment, existing links and primary outlines only |
| Destructive/error | `#ef4444` | Local clipboard failure and destructive actions only |

Supporting semantic colors: primary text `#e2e8f0`, muted/disabled text `#94a3b8`, success `#4ade80`.

Accent reserved for: copy affordance hover and keyboard focus, existing links, and existing primary control outlines. Resting copy controls do not consume accent color. Success green is transient feedback, not an accent substitute.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | `Copy {field}` — field-specific accessible/hover text, e.g. `Copy docket` |
| Empty state heading | `N/A` |
| Empty state body | `Nothing extracted to copy.` |
| Success state | `Copied` |
| Error state | `Couldn't copy.` — remain on the field and allow retry |
| Destructive confirmation | None; this phase has no destructive action |

Use sentence case. Do not add punctuation to `Copied`; include the period in the explanatory disabled and error messages. The visible copied value remains unchanged while transient feedback appears immediately beside it, preventing ambiguity about which value was copied.

## Responsive and Accessibility Contract

- Controls may wrap with their existing hint row, but value and trailing icon never split across lines; use `inline-flex` with `align-items: center`.
- Long values may wrap inside the unified button when necessary, with the icon retained after the final text; do not truncate because copied text must match visible text.
- Native button activation must support Enter and Space without custom key handlers.
- Do not rely on color alone: success displays `Copied`, failure displays `Couldn't copy.`, and disabled state retains `N/A` plus disabled semantics.
- `aria-live` feedback must be local to the activated control so simultaneous instances do not announce unrelated field state.
- Disabled controls are not focusable. Because disabled elements do not reliably expose hover content to every input mode, the accessible disabled state comes from native `disabled` plus the visible `N/A`; the specified title is supplemental.
- Respect `prefers-reduced-motion`; the contract requires no animation, only an immediate state swap and timed reset.
