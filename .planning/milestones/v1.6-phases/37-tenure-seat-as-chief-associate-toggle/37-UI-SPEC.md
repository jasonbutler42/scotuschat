# Phase 37 — UI Design Contract

> Visual and interaction contract for replacing tenure Seat free text with a constrained Office control. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | Existing project-native Svelte components and inline styles; no shadcn |
| Preset | not applicable |
| Component library | none |
| Icon library | none required for this phase |
| Font | `system-ui, -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif` |

The Office control must reuse the existing Bench/Advocate two-segment visual idiom in the people editor. Do not introduce a new shared component library, icon dependency, dropdown, checkbox, switch, or free-text fallback in this phase.

Declared values (all multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Inline text gaps and compact status spacing |
| sm | 8px | Label-to-control gap, segment vertical padding, error separation |
| md | 16px | Field gaps, segment horizontal padding, tenure-row internal rhythm |
| lg | 24px | Tenure sub-card and parent-card padding |
| xl | 32px | Reserved layout gap; no new Phase 37 exception |

Exceptions: interactive Office segments retain the established `min-height: 44px` accessibility target. Existing 6px radii and 1px borders are component geometry, not spacing tokens.

## Typography

Use only the two established weights, 400 and 600.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Supporting/popover text | 13px | 400 | 1.4 |
| Field label and validation | 14px | 400 | 1.4 |
| Segment, body, and tenure title | 16px | 400 or 600 | 1.5 |
| Section/page heading | 20px | 600 | 1.2 |

The `Office` legend uses the existing 14px/400 muted-label treatment. `Chief` and `Associate` use 16px/600. Invalid legacy value and corrective error copy use 14px/400; color and semantics, not heavier type, communicate the error.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0f1117` | Page background, tenure sub-card inset surface, selected-segment text |
| Secondary (30%) | `#1e293b` | Admin cards, unselected segment, inputs and popover surface |
| Accent (10%) | `#93c5fd` | Selected Office segment fill/border, focus-visible outline, existing primary action border and links |
| Destructive/error | `#ef4444` | Invalid-office border/error text and existing destructive actions only |

Supporting neutrals: `#334155` for borders and inactive segment boundaries; `#e2e8f0` for primary text; `#94a3b8` for labels and secondary text.

Accent reserved for: selected `Chief` or `Associate` segment, keyboard focus indication, the existing `Save Person` affordance, and existing navigation/add links. It must not color both segments simultaneously.

The invalid state uses `#ef4444` on the Office group boundary/error text while preserving a clearly distinguishable selected accent once the operator makes a valid corrective choice.

## Component and Interaction Contract

The Office segmented control is the tenure row's primary visual anchor. When legacy data is unresolved, its inline Office error becomes the row's immediate visual priority; `Save Person` remains the profile-level action.

### Office segmented control

- Replace each tenure row's `Seat` text input with a fieldset/radiogroup labeled `Office` containing exactly two adjacent segments in this order: `Chief`, `Associate`.
- Use native radio semantics where practical; otherwise the existing buttons must expose `role="radiogroup"` on the container, `role="radio"`, `aria-checked`, and roving keyboard focus. Left/Right Arrow moves selection, Space selects, and Tab enters/exits the group once.
- Each segment is at least 44px high with 8px vertical and 16px horizontal padding. The first segment has 6px left radii; the second has 6px right radii; the shared internal edge is not doubled.
- Selected: `#93c5fd` background and border with `#0f1117` text. Unselected: `#1e293b` background, `#334155` border, and `#e2e8f0` text.
- Focus-visible uses a clearly visible `#93c5fd` outline with at least 2px thickness and separation from the control. Focus must remain visible in selected and unselected states.
- Exactly one valid option is selected for normal data. Clicking the selected option is idempotent and cannot clear it.
- A newly added tenure row starts with `Associate` selected. This default is local form state and is serialized as `office`; it is not placeholder text.
- Changing Office does not submit immediately. It remains local with the row's dates and other tenure fields until the existing `Save Person` action persists the whole profile atomically.

### Invalid legacy office state

- If an unrecognized or blank legacy value reaches the editor, do not preselect `Chief` or `Associate` and do not replace the original value with a guessed default.
- Render a persistent inline message immediately below the Office group with `role="alert"` (or an associated live error region): `Unrecognized office: “{original value}”. Select Chief or Associate before saving.` For blank legacy data, substitute `No office was recorded.` for the first sentence.
- Associate the error to the group with `aria-describedby` and expose invalid state with `aria-invalid="true"` on the group or its focusable options.
- Show the original invalid value as inert text inside the error, never in an editable input. Preserve it until a valid option is explicitly selected so the operator can make an informed correction.
- Selecting either valid segment clears the row's invalid visual/error state in local form state. Save remains blocked if any tenure row is unresolved; the form-level response must identify the affected tenure row and focus the first invalid Office group.
- Server-returned validation must restore all submitted tenure values and selections. It must not erase other unsaved profile edits.

### Read-only titles

- Public popovers and all read-only tenure summaries map the stored office to formal display copy: `chief` → `Chief Justice`; `associate` → `Associate Justice`.
- Retain the existing tenure date presentation and date-window semantics. The title precedes the date range, e.g. `Associate Justice — 1981–2005`.
- Do not display `Chief`, `Associate`, raw enum values, the old numbered seat, or the generic fallback `Justice` for valid records.

### Responsive behavior

- Keep the two Office segments on one row at all supported widths; each may flex equally to use the available tenure-card width.
- Do not truncate the segment labels. Error copy wraps below the group without horizontal scrolling.
- Preserve the existing two-column Start Date/End Date layout and current page breakpoints; Phase 37 does not restructure the tenure card.

## States

| State | Visual and behavior contract |
|-------|------------------------------|
| Existing valid Associate | `Associate` selected; `Chief` unselected |
| Existing valid Chief | `Chief` selected; `Associate` unselected |
| New tenure row | `Associate` selected immediately |
| Hover | Preserve state; apply only the established subtle pointer affordance, with no layout shift |
| Keyboard focus | 2px-or-greater visible accent outline; keyboard operation matches radio behavior |
| Invalid legacy value | Neither option selected, destructive group/error treatment, original value visible, entire profile save blocked |
| Corrected but unsaved | Chosen option selected in accent; correction remains local until `Save Person` |
| Saving | Existing `Saving…` form state; Office controls follow the form's submission lock to prevent conflicting edits |
| Server error | Selections and other tenure edits restored; clear problem-and-remedy message remains associated with the row |
| No tenure rows | No separate empty-state panel; retain `+ Add Tenure Period` as the next action |

## Copywriting Contract

| Element | Copy |
|---------|------|
| Field legend | `Office` |
| Segment labels | `Chief`; `Associate` |
| Primary CTA | `Save Person` (existing profile-level action; saving state `Saving…`) |
| Add-row CTA | `+ Add Tenure Period` |
| Empty state heading | none; do not add a new empty-state heading inside the existing compact editor |
| Empty state body | none; the persistent `+ Add Tenure Period` action is sufficient |
| Invalid nonblank office | `Unrecognized office: “{original value}”. Select Chief or Associate before saving.` |
| Invalid blank office | `No office was recorded. Select Chief or Associate before saving.` |
| Form-level blocked save | `Select Chief or Associate for every tenure period before saving.` |
| Read-only titles | `Chief Justice`; `Associate Justice` |
| Destructive confirmation | No new destructive action. Existing `Remove` tenure behavior is unchanged by this phase. |

Copy must use `Office`, never `Seat` or `Role`, throughout the editor, errors, payload-facing validation messages, and read-only UI. `Role` remains reserved for argument-specific roles.
