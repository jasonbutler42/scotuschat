<objective>
Third layer of the G-38-6 fix: give the operator immediate, specific feedback at the
control where the bad value is actually typed, and re-check on the SvelteKit server so a
forged form field cannot reach FastAPI carrying a misleading generic error.

The backend layers (plans 38-07, 38-08) are authoritative and already close the
vulnerability. This plan closes the third item in the UAT gap's `missing` list — the
operator currently gets no feedback until the job fails, and even then the pipeline page's
catch-all copy talks about the URL rather than the docket.

Purpose: the reported failure mode was an operator typing free text into a control that
accepted anything and then discovering the problem as a crashed job.
Output: a parity-locked TypeScript mirror of the shared rule, an inline error in
`DocketPillInput`, a SvelteKit-server re-check with accurate copy, and a Python contract
test that keeps the two languages from diverging.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser DOM → SvelteKit form action | Hidden `docket[]` inputs are forgeable; the browser check is UX, not enforcement |
| SvelteKit action → FastAPI `create_job` | The action forwards multipart fields on behalf of an authenticated admin |
| Shared rule → two language implementations | A divergent client rule could imply a value is safe when it is not, or vice versa |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-38-23 | Tampering | forged `docket[]` hidden inputs | medium | mitigate | The SvelteKit action re-checks every raw docket value server-side and the FastAPI boundary (plan 38-07) remains authoritative, so bypassing the browser gains nothing |
| T-38-28 | Tampering | TypeScript/Python rule divergence | medium | mitigate | `api/tests/test_docket_ui_contract.py` extracts the client pattern literal and cap and asserts equality with the Python constants, then replays the shared fixture through the extracted rule so codes agree case-for-case |
| T-38-29 | Information Disclosure | SvelteKit failure copy | low | mitigate | The docket failure message is fixed text plus the shared cap; the submitted value is never echoed and FastAPI's 422 detail is never forwarded verbatim (T-07-13 posture retained) |
| T-38-30 | Denial of Service | regression on the metadata editor | low | mitigate | `enforceShape` defaults to false and only the Pipeline Runner opts in, so `ArgumentDetailsCard`'s already-persisted legacy docket values keep rendering and saving unchanged (asserted by a contract test) |
</threat_model>
