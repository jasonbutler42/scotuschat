## Component and Layout Contract

### Generated Full Name

- Replace the editable Full Name input on standalone create and person edit with a read-only preview in the same Identity card and first layout position.
- Label it `Full Name` and place `Generated from name parts.` immediately beneath or beside the label in 14px muted text. Do not style the preview like an enabled text input and do not submit a client-owned `full_name` field.
- Render the live canonical value `First Middle Last, Suffix`, omitting blank components and punctuation. Use `N/A` in muted italic text until First Name or Last Name is present.
- The preview updates immediately as name-part inputs change. It preserves authored capitalization and punctuation and normalizes whitespace only; examples are `Amy Coney Barrett` and `John G. Roberts, Jr.`.
- First Name and Last Name labels communicate the shared invariant with one concise hint above the group: `Enter at least a first or last name.` Do not mark both fields individually required.

### Name-part fields and provenance

- Keep First, Middle, Last, and Suffix in the existing grid order. Desktop uses `1fr 1fr 1fr 80px` with 16px gaps; at the existing narrow breakpoint use two equal columns. Each extracted stack remains inside its field column rather than spanning the row.
- Beneath each editable name-part input, render the shared extracted stack when provenance exists. Operator values remain visually primary; extraction is reference material and never resembles a second editable input.
- First line is exactly `Extracted: {interpreted value}`. The interpreted value and trailing copy icon form one native button and copy exactly the displayed interpretation.
- Second line is exactly `{High|Medium|Low} confidence · Raw: {exact source text}`. Confidence must always be textual. Raw text wraps and is never truncated, normalized, title-cased, or hidden behind a tooltip.
- If no extracted interpretation exists, retain the Phase 36 disabled `N/A` copy state. Omit a meaningless confidence/raw line unless raw source text exists independently; if raw exists with no interpretation, show the disabled `N/A` first line and `Low confidence · Raw: {exact source text}` second line.
- Long values wrap within their own column. The copy icon remains attached after the interpreted value; the second line may wrap at spaces and `Raw:` content may use `overflow-wrap: anywhere`.

### Docket Pill provenance

- Implement the editable/read-only, single/multiple, mixed-confidence, long-raw, remove, copy, and copied states defined by `38-FIGMA.md` component set `3:140` and review sheet `3:2`.
- Preserve the interpreted docket as primary pill content. Place the provenance line below it using the same qualitative confidence and exact raw-source contract as other extracted fields.
- Copy and copied feedback belong to the interpreted displayed docket. Remove appears only in editable mode. Confidence uses text plus color; never color alone.
- Existing Docket Pill geometry comes from the editable Figma component, not measurement from the fallback PNG.

### People directory name review

- Add `Name review` to the existing attention/filter vocabulary rather than creating a dashboard or queue.
- A flagged row shows a compact visible `Name review` indicator near its existing missing-data indicators. Selecting the filter returns only records requiring name review and preserves the directory's current URL/filter/navigation behavior.
- Empty filtered state heading is `No people need name review`; body is `Ambiguous legacy names will appear here for review.`

## Interaction and State Contract

| State | Visual contract | Behavior/accessibility contract |
|-------|-----------------|---------------------------------|
| Generated preview ready | 16px primary text on an inset `#0f1117` surface with `#334155` border; generated hint remains visible | `aria-live="polite"` may announce the updated preview, but must not announce on every keystroke if the implementation cannot debounce cleanly; the visible label/hint is mandatory |
| Generated preview empty | Visible italic `N/A` in `#94a3b8` | Save is rejected unless First or Last is present; focus the first applicable name-part field and show the form error |
| Extracted rest | Interpreted value is primary within the muted hint stack; raw/confidence line is subordinate | Field-specific accessible label, e.g. `Copy extracted first name`; exact interpreted display string is copied |
| Extracted hover/focus | Existing `#93c5fd` accent; global 2px focus outline with 3px offset | Native Enter/Space activation; no custom keyboard handler |
| Extracted copied/error/N/A | Preserve Phase 36 `Copied`, `Couldn't copy.`, and disabled `N/A` visuals and timing | Local live region/error only; 1,500ms reset; stale promise/timer generations cannot update a changed payload |
| Confidence | High/Medium/Low appears as visible text; optional restrained semantic color may supplement it | Never expose a percentage or imply statistical calibration |
| Name review | Compact text indicator aligned with existing attention pills | Filter is a labeled native control/link and has a visible selected state |
| Save validation | Error in `#ef4444` adjacent to the identity form without clearing attempted parts | Message: `Enter at least a first or last name.`; preserve attempted values and move focus to the relevant field |

Operator edits never overwrite extracted provenance. New extraction may prefill only blank saved fields; later extraction refreshes the reference while leaving saved fields untouched. These are data transitions, so do not add confirmation dialogs or transient overwrite UI.

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Stack line gap, value-to-copy-icon gap |
| sm | 8px | Label-to-input gap, compact target padding, extracted stack top gap |
| md | 16px | Field/grid gaps and default section rhythm |
| lg | 24px | Existing card padding |
| xl | 32px | Layout gaps |
| 2xl | 48px | Page content spacing |
| 3xl | 64px | Page-level spacing when already used |

Exceptions: retain the Phase 36 36px minimum copy target height; primary form buttons remain 44px minimum height; existing focus outline uses a 3px offset. The narrow 80px Suffix column is an approved grid dimension, not a spacing token.

## Typography

Use exactly four sizes and two weights:

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Compact pill/status | 12px | 400 | 1.5 |
| Label, hint, provenance, feedback | 14px | 400 | 1.5 |
| Input, generated preview, control body | 16px | 400 | 1.5 |
| Card/page heading | 20px | 600 | 1.2 |

Do not add a bold confidence tier, third weight, uppercase label system, or smaller raw-source text. `Extracted:`, confidence, and `Raw:` remain readable at 14px/400.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0f1117` | Page background and inset control/preview surfaces |
| Secondary (30%) | `#1e293b` with `#334155` borders | Cards, navigation, default pills and controls |
| Accent (10%) | `#93c5fd` | Copy hover/focus, selected directory filter, existing links and primary outlines |
| Destructive/error | `#ef4444` | Validation/copy errors and existing destructive actions only |

Supporting colors: primary text `#e2e8f0`, muted/disabled/provenance text `#94a3b8`, copy success `#4ade80`. Confidence must remain legible without its optional semantic color; do not introduce percentage-style progress colors or fill the entire extracted stack with accent.

Accent reserved for: copy hover/focus, selected `Name review` filter, existing links, and existing primary control outlines. Resting provenance and generated preview do not consume accent.

## Responsive and Accessibility Contract

- At wide widths retain the four-column name grid; at the existing narrow breakpoint use two columns. Each label, input, and extracted stack forms one grid item. Never preserve the 80px Suffix width when it causes raw provenance to become unreadable at narrow widths.
- The two provenance facts remain two semantic lines. They may wrap internally but must not collapse into a tooltip, ellipsis, or horizontally scrolling strip.
- `CopyableExtractedValue` retains native button, disabled, focus, live-region, failure, cleanup, and payload-generation behavior from Phase 36. Extend it with optional confidence/raw presentation without regressing consumers that supply only a value.
- Confidence is expressed in visible words. Copy success/error and selected filter state also use text or structural state, not color alone.
- Generated Full Name is programmatically associated with its label and explanation. Prefer an output/readout element over `disabled` input semantics; if `readonly` input is used, it remains focusable and is clearly described as generated.
- All form errors use `role="alert"`, preserve submitted values, and provide a focus path. The shared First-or-Last rule must not be represented with misleading `required` attributes on both fields.
- Raw source can contain untrusted text. Display it as plain text, allow wrapping, and never execute, parse as markup, or use it as an accessible label without a stable field prefix.
- No animation is required. Respect `prefers-reduced-motion`; state changes are immediate.
