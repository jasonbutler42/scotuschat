## Identity model: the primary noun is the fixture SET

- **Primary noun:** the **fixture set** — four records of one uniform shape (ConvoKit conversation id, case name, docket(s), term, argued date) discriminated by a single `Role` value. This document must NOT be structured as "the fixture" plus an appended list of extras.
- **Decision:** **promote.** CONTEXT.md D-01/D-07/D-08 already made this promotion during discuss-phase; ROADMAP.md (Phases 41/42/43) and REQUIREMENTS.md (CORPUS-12, DEVTOOL-01) were edited in that same session to match. This plan encodes the already-promoted model and does not re-open it.
- **Rationale:** matches CONTEXT.md's own stated widening (D-01) — Phase 42 reads one row and Phase 43 reads all four rows out of one table, which only works if all four rows share a shape.
- **Consequence for this plan:** `.planning/FIXTURES.md`'s fixture table is a single four-row table with a `Role` column. Four separate per-fixture sections, or a distinct schema for the complexity fixture, would violate the promoted model.
</assumption_delta_decision>
