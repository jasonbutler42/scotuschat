<objective>
Replace the interim ingestion-prefixed wording on bench rows with the copy the canonical design
specifies, add the missing third bench state, and make the tenure-fix path open in a second tab.

Purpose: the bench Argument Role and Descriptor cells were given the same "this value was ingested"
treatment as every other cell in 44-04, which was honest for corpus-passthrough data but is wrong for
these two: the bench role is computed from `court_tenures` on every read and was never ingested at all,
and the bench descriptor is deliberately hidden rather than absent. This plan makes each cell say what
is actually true about its value — calculated, not found, or not yet computable — and adds the
new-tab link that makes the live recompute 44-06 locked actually usable, since correcting tenure
requires leaving this page.

Output: three mutually-exclusive bench Argument Role states with their canonical copy, a bench
Descriptor cell with a bare dash and no hint, a new-tab `Edit person` link, and advocate rows unchanged.

## Deltas resolved here (reconciliation-doc gaps, not re-asks)

1. **Which field identifies "unresolved bench".** Canonical point 7 says "unresolved bench role", and
   diff row 8 describes today's behaviour as the locked box falling back to a dash "when bench + no
   person". Verified while planning: for a bench participant with a null `person_id` the service
   returns `bench_role: null` and `missing_tenure: **false**` (`api/services/admin_people.py`, the
   `if participant.person_id is not None else (None, False)` branch) — so `missing_tenure` cannot
   distinguish unresolved from calculated. Resolution: the unresolved state keys on `row.person_id`
   being null and is checked *before* the calculated state, or an unresolved row would fall into the
   locked box with nothing to show.
2. **Where the two new strings sit relative to the control.** Canonical point 5 gives the wording but
   not the placement. Resolution: each string occupies the slot the retired ingestion hint used — a
   line directly beneath its cell's control — so the cell's vertical rhythm matches the advocate cells
   next to it. `Calculated from tenure` sits under the locked box; `Tenure not found` sits under the
   `⚠ Missing tenure` line, above the `Edit person` link.
3. **What happens to the two hint call sites.** Canonical point 5 says the bench role is "not an
   ingestion hint at all", and diff row 6 says to suppress the descriptor hint on bench rows.
   Resolution: both `CopyableExtractedValue` call sites stay in the file with the source-aware prefix
   44-07 gave them, each wrapped in a non-bench condition. Wrapping rather than deleting keeps advocate
   rows byte-identical and keeps 44-07's exactly-four-derived-prefix contract intact.
4. **The `↗` glyph.** Canonical point 5 writes the link as `Edit person ↗`. Resolution: render the
   glyph as a separate `aria-hidden` span after the link text so the accessible name stays `Edit person`
   and the arrow is not read aloud, matching how the `⚠` glyph is handled on the warning line.
