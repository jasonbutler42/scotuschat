    `TRUSTED = "trusted"`, `PROVISIONAL = "provisional"`, `UNCERTAIN = "uncertain"`.
  - `_TIER_ORDER: dict[TrustTier, int]` mapping UNCERTAIN to 0, PROVISIONAL to 1,

    `"corpus"`, `"pdf_pipeline"`, `"seed"`; `"manual"`, `"direct"`, `"normalized"`,
    `"rule_based"`, `"llm_corrective"`), not the enum objects, so the pure module stays
    free of a models import. Evaluate rules in this exact precedence order, first match
    wins, and state the order in the docstring:
      1. `review_state` in `{"operator_confirmed", "operator_edited"}` -> `VERIFIED`
      2. `review_state == "needs_review"` -> `UNCERTAIN`
      3. `source == "operator" and method == "manual"` -> `VERIFIED`
      4. `(source, method)` in `{("corpus", "direct"), ("seed", "direct")}` -> `TRUSTED`
      5. `method == "normalized"` -> `PROVISIONAL`

    `TrustTier.UNCERTAIN` when the sequence is empty — never a bare `min()` on an empty
