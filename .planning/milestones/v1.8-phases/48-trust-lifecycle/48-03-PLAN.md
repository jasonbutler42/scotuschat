<objective>
Turn the apolitical hard constraint into an automated gate: assert that trust never appears
on a public response, structurally against every public Pydantic model and behaviourally
against every public endpoint.

Purpose: D-23 exists because "public response models are explicit Pydantic allow-lists" is
a structural safety property nobody has ever asserted. A single `model_config` change or a
copy-pasted admin field would breach the constraint silently. This plan makes that breach
red.

Output: one new pure contract-test module plus an extension of the existing Phase 47
leak-ban block.
</objective>
