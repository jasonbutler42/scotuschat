## Flagged planner assumptions (surfaced, not silently applied)

- **Edge probe TRUST-02 (`unclassified`)** — left unresolved by the probe. This plan builds
  the instrument that closes it: the unclassified edge is "a writer skipped its recompute",
  and `--all` reporting a non-zero changed count after a fresh reseed is exactly the
  detector. Recorded here rather than dropped; plan 48-09 executes the check.
- **One session per argument, not one session for the whole scan.** 48-RESEARCH.md does not
  specify the transaction granularity. Per-argument sessions are chosen so a mid-scan failure
  leaves earlier repairs durable and so each write stays a bounded transaction; the cost is
  more round trips on a large `--all` run, which is acceptable for an operator-run offline
  repair tool. Flagged so a reviewer can object rather than discover it.
</flagged_assumptions>
