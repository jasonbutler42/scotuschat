## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Inline gaps (avatar-to-label gap, pill-to-pill gap in mobile nav) |
| sm | 8px | Intra-element spacing (bubble header margin-bottom, SectionRail button margin-bottom) |
| md | 16px | Default element padding (bubble horizontal padding, card padding, header padding) |
| lg | 24px | Same-speaker turn gap; section rail padding; header top/bottom padding |
| xl | 32px | Different-speaker turn gap |
| 2xl | 48px | Chat column top/bottom padding; stage direction top/bottom margin |
| 3xl | 64px | Not used in Phase 4 surface |

Exceptions:
- Avatar circle: 32px fixed dimension — not a spacing token; it is a fixed component size.
- Avatar font-size: 12px — documented exception to the 3-4 type scale; it is a fixed UI affordance for initials in a 32px circle (source: Phase 3 UI-SPEC).
- Mobile nav bar height: ~44px — ensures minimum thumb-reachable touch target (WCAG 2.5.5 advisory). Not a spacing token; it is a minimum component height.
- Chat column bottom padding when mobile nav visible: 60px — prevents last utterance from being hidden behind fixed mobile bar.
- Focus ring offset: 3px — not a spacing scale value; it is a CSS `outline-offset` specific to the focus ring rule.

## Interaction Contract

### Focus Ring (A11Y-02 / D-05, D-06, D-07)

Single global rule in `app/src/app.css` — covers all current and future interactive elements.

```css
*:focus-visible {
    outline: 2px solid #93c5fd;
    outline-offset: 3px;
    border-radius: 4px;
}
```

- Applies to: all `<a>`, `<button>`, and any future focusable elements site-wide.
- `border-radius: 4px` matches `SectionRail` button border-radius — visually cohesive.
- `outline-offset: 3px` prevents the ring from touching the element edge.
- `focus-visible` pseudo-class ensures the ring shows for keyboard users but not mouse click users.
- Browser support: Chrome 94+, Firefox 83+, Safari 16+ (all current targets).

### Keyboard Navigation (A11Y-02)

Every interactive element must be reachable via Tab and activated via Enter/Space:

| Element | Keyboard behavior |
|---------|-------------------|
| Global nav "Cases" link | Tab to focus, Enter to navigate |
| Case list card links | Tab to focus, Enter to navigate |
| SectionRail buttons (desktop) | Tab to focus, Enter or Space to scroll |
| Mobile nav pills (new, `<768px`) | Tab to focus, Enter or Space to smooth-scroll |

No mouse-only interactions are introduced in Phase 4.

### Screen Reader Semantics (A11Y-03 / D-08, D-09, D-10)

| Component | Change | Attribute |
|-----------|--------|-----------|
| `+layout.svelte` global nav `<nav>` | Outer `<div>` → `<nav>` already exists; add `aria-label` | `aria-label="Site navigation"` |
| Every page outer wrapper `<div>` | Replace with `<main>` | `role="main"` implicit via element |
| Every page top bar `<div>` | Replace with `<header>` | `role="banner"` implicit via element |
| `ChatBubble.svelte` outer wrapper `<div>` | Add `role` + `aria-label` | `role="article"` + `aria-label="{isBench ? 'Bench' : 'Advocate'}: {displayName}"` |
| `StageDirection.svelte` outer `<div>` | Add `role` | `role="note"` |
| `SectionRail.svelte` `<nav>` | Add `aria-label` | `aria-label="Argument sections"` |

Speaker side is conveyed by `aria-label` text ("Bench: [Name]" / "Advocate: [Name]") — not by color alone. Satisfies A11Y-03 for assistive technology users (D-09).

### Mobile Section Navigation (D-11, D-12, D-13)

New component: `MobileNavBar.svelte` (or inline in argument page `<style>` block — planner's choice).

| Property | Value |
|----------|-------|
| Visibility | Shown only at `<768px` (same breakpoint as desktop rail hide) |
| Position | `position: fixed; bottom: 0; left: 0; right: 0` |
| Background | `#1e293b` (secondary surface) |
| Border top | `1px solid #334155` |
| Layout | `display: flex; flex-direction: row; overflow-x: auto; gap: 8px; padding: 8px 16px` |
| Pill shape | `border-radius: 20px; padding: 6px 14px; font-size: 13px; font-weight: 400` |
| Inactive pill | `background: transparent; color: #94a3b8; border: 1px solid #334155` |
| Active pill | `background: #1e293b; color: #e2e8f0; border: 1px solid #93c5fd` |
| Minimum height | 44px (thumb-reachable touch target) |
| Scroll behavior | `scrollIntoView({ behavior: 'smooth' })` — identical to desktop SectionRail |
| Hidden when | `sectionAnchors.length === 0` — no sections detected |
| Chat column | Add `padding-bottom: 60px` to chat column `<div>` when mobile nav is visible |
| Data | Consumes `sectionAnchors` derived value already computed in the argument page |
| Runes pattern | Wraps `IntersectionObserver` in `$effect(() => { if (!browser) return; ... })` |
| Active state | `activeSection` tracks same scroll-spy logic as `SectionRail` |
