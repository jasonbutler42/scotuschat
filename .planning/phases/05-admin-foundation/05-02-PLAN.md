<objective>
Create the FastAPI admin router (`api/routers/admin.py`) with a throwaway `X-Admin-Token` auth dependency injected at the router level, a single `GET /api/admin/health` smoke-test route, and mount it in `api/main.py` alongside the existing arguments/cases/people routers.

Purpose: Gives Phase 6 (auth) and Phase 7 (pipeline runner) a mounted, protected router to build on. The auth dependency is deliberately placed in the `APIRouter(dependencies=[...])` constructor (per D-12, the specifics section) so Phase 6 can replace `verify_admin_token` with HMAC session-cookie auth in exactly one place without touching route signatures. The token is a throwaway with no permanent dev bypass.

Output: `api/routers/admin.py`, a one-import + one-mount change to `api/main.py`, and a static-analysis smoke test.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → admin router | Untrusted HTTP requests cross into protected admin surface; X-Admin-Token header is the only gate in Phase 5 |
| router → config secret | `verify_admin_token` reads `settings.admin_token` to compare against the inbound header |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-04 | Spoofing | `GET /api/admin/health` | mitigate | Router-level `dependencies=[Depends(verify_admin_token)]` enforces the X-Admin-Token check on every route; missing/wrong header → 401 before the handler runs. |
| T-05-05 | Information Disclosure | `verify_admin_token` | mitigate | Compare only; never log or echo `x_admin_token` or `settings.admin_token`. 401 response body is the constant string "Unauthorized" — no token, no timing-revealing detail returned to the client. |
| T-05-06 | Elevation of Privilege | Phase 6 swap surface | accept | Throwaway token is intentionally weak (per D-12) and replaced wholesale by HMAC session cookies in Phase 6; the router-level dependency placement keeps that swap to a single line. No permanent dev bypass is added. |
| T-05-07 | Tampering | SvelteKit routes | accept | Phase 5 touches zero `app/` files (D-14); no client-side attack surface introduced this phase. |
</threat_model>
