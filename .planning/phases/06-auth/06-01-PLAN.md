<objective>
Build the stateless HMAC session contract and the SvelteKit `hooks.server.ts` route guard — the foundation both the login flow (Plan 02) and the admin shell (Plan 03) depend on.

This plan delivers the single source of truth for signing and verifying the `scotus_admin_session` cookie (`app/src/lib/server/session.ts`), wires the guard that intercepts every `/admin/*` request except `/admin/login` (D-05, D-07, D-10), declares the `App.Locals.session` type so downstream load functions can read `locals.session`, and adds env-var documentation to `api/core/config.py` and `.env.example` (D-04, D-15).

Purpose: AUTH-02 — protect all admin routes (pages AND `+server.ts` endpoints) at the hooks layer, which runs before any layout/page `load`. Centralizing sign/verify avoids the guard and the login action drifting apart.
Output: `session.ts` (sign/verify/cookie-name), `hooks.server.ts` (handle export), `app.d.ts` (Locals typing), `config.py` + `.env.example` documentation.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → SvelteKit server | Untrusted cookie value crosses here; guard must verify before trusting |
| operator → admin routes | Unauthenticated traffic must be rejected before any content renders |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-01 | Spoofing | scotus_admin_session cookie | high | mitigate | Cookie is HMAC-SHA256 signed with SESSION_SECRET; `verifySession` recomputes and compares via `timingSafeEqual`; forged/tampered cookies fail verification (Task 1, Task 2) |
| T-06-02 | Elevation of Privilege | /admin/* endpoints (+server.ts) | high | mitigate | Guard lives in `hooks.server.ts` which runs before all load/endpoint handlers (D-05), so API endpoints are protected, not just pages (Task 2) |
| T-06-03 | Information Disclosure | session expiry forgery | medium | mitigate | Expiry timestamp is inside the signed payload; tampering the timestamp invalidates the HMAC; expired sessions rejected by `expiry > Date.now()` check (Task 1) |
| T-06-04 | Tampering | timingSafeEqual length-mismatch throw | low | mitigate | `verifySession` returns false on length mismatch BEFORE calling timingSafeEqual to avoid the throw becoming a 500 (Task 1) |
| T-06-05 | Information Disclosure | SESSION_SECRET exposure | high | mitigate | SESSION_SECRET imported only from `$env/static/private` (server-only, never PUBLIC_); `.env.example` ships empty placeholder, never a real value (Task 1, Task 3) |
| T-06-SC | Tampering | npm/pip/cargo installs | low | accept | No new package installs in this plan — uses node:crypto (stdlib) and @sveltejs/kit (already in package.json); no supply-chain surface added |
</threat_model>
