## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| SvelteKit server → FastAPI | Server-to-server calls authenticated by X-Admin-Token; untrusted operator form input crosses here |
| FastAPI → pipeline subprocess | Typed args (int job_id, validated str url/key) passed via argv, shell=False |
| FastAPI → DO Spaces | boto3 SigV4-signed uploads with credentials from server-only env vars |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Spoofing/Elevation | `pdf_url` reaching subprocess (SSRF) | mitigate | URL validated against `supremecourt.gov` https in Plan 02 route before create_job + subprocess spawn (defense in depth; pipeline `_validate_url` is second layer) |
| T-07-02 | Tampering | `spawn_pipeline_step` argv | mitigate | shell=False (default); args are typed (int job_id, validated str); never interpolated into a shell string |
| T-07-SC | Tampering | boto3 install (supply chain) | mitigate | blocking-human checkpoint verifies boto3 on pypi.org/project/boto3 (official AWS SDK) before reliance |
| T-07-03 | Information Disclosure | DO Spaces credentials | accept | credentials live only in server-only env vars (settings); never returned in any response; consistent with existing admin_token handling |
</threat_model>
