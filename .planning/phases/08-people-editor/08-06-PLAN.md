# Phase 08 Plan 06: Gap Fix — ArgumentParticipant Population

## Root Cause

`argument_participants` rows are never inserted by the pipeline. `resolve.py` Step 5 runs `UPDATE argument_participants SET person_id = ...` against rows that don't exist, making every UPDATE a no-op. `list_participants_for_job` then returns an empty list, and the participants section never renders.

## Fix

After the utterance write loop in `pipeline/commands/parse.py` (Step 7), collect unique `(raw_speaker_label, side)` pairs from the parsed utterances (excluding stage directions and null labels), check which ones don't already exist in `argument_participants` for this argument, and INSERT the missing rows with `person_id = None`.

## Tasks

### Task 1 — Insert ArgumentParticipant rows in parse step

**File:** `pipeline/commands/parse.py`

After the utterance `session.flush()` at the end of Step 7 (line ~251), add a new Step 7b:

```python
# Step 7b: Seed argument_participants for each unique speaker label (PEOPLE-04).
# person_id is NULL here — the Resolve step sets it via UPDATE.
# Uses select-before-insert to be safe on parse re-runs.
participant_labels = {
    (u["raw_speaker_label"], SideEnum(u["side"]))
    for u in utterances
    if u.get("raw_speaker_label") and not u.get("is_stage_direction")
}
if participant_labels and run.argument_id is not None:
    existing_result = await session.execute(
        select(ArgumentParticipant.raw_speaker_label).where(
            ArgumentParticipant.argument_id == run.argument_id
        )
    )
    existing_labels = {row[0] for row in existing_result.all()}
    for raw_label, side in participant_labels:
        if raw_label not in existing_labels:
            session.add(ArgumentParticipant(
                argument_id=run.argument_id,
                raw_speaker_label=raw_label,
                side=side,
                person_id=None,
            ))
    await session.flush()
    print(f"Seeded {len(participant_labels - {(l, s) for l, s in participant_labels if l in existing_labels})} argument_participant row(s).")
```

Also add `select` to sqlalchemy imports — already imported.
