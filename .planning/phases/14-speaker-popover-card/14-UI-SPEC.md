## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Avatar-to-name gap in roster trigger row; margin between heading lines in popover |
| sm | 8px | Gap between avatar and name in bubble header; gap between tenure rows; popover internal row gaps |
| md | 16px | Popover horizontal padding; gap between avatar column and text column on desktop |
| lg | 24px | Popover vertical padding; roster section margin-top |
| xl | 32px | Popover max-width buffer; gap between popover sections (photo block vs. details block) |
| 2xl | 48px | Not used in this phase |
| 3xl | 64px | Not used in this phase |

Exceptions: Avatar trigger circles (32px in chat bubbles and roster) and popover photo/initials circle (60px) are dimension values, not spacing tokens. Touch target minimum for avatar buttons: 44px — achieved by padding the button interior to reach 44px hit area while keeping the visible circle at 32px.

Source: CONTEXT.md D-10, Specifics section; codebase inspection of ChatBubble.svelte.

## Component Inventory

### SpeakerPopover.svelte (new)

**Purpose:** Floating card content displaying speaker identity. Rendered once at the argument page level inside `Popover.Content`. Receives a `SpeakerDetail` object as a prop.

**Props:**
```ts
interface SpeakerDetail {
  person_id: number;
  full_name: string;
  role_name: string | null;
  photo_url_full: string | null;   // reconstructed server-side; null = show initials
  is_bench: boolean;
  tenure: { seat: string; start_date: string; end_date: string | null }[];
  appointing_president: string | null;
}
```

**Layout — desktop (≥768px):**
```
┌──────────────────────────────────────────┐
│  [60px circle]  Full Name               │
│  photo/initials  Role Name              │
│                  ─────────────────────  │
│                  (bench only)           │
│                  Chief Justice — 2005–present │
│                  Appointed by John Roberts    │
└──────────────────────────────────────────┘
```
- `display: flex; flex-direction: row; align-items: flex-start; gap: 16px; padding: 24px;`
- Card min-width: 280px; max-width: 360px.
- Card surface: `background-color: #1e293b; border: 1px solid #334155; border-radius: 8px;`

**Layout — mobile (<768px):**
- `flex-direction: column; align-items: center; text-align: center;`
- Photo/initials circle remains 60px, centered above text.

**Photo circle (60px):**
- When `photo_url_full` is present: `<img src={photo_url_full} alt={full_name}` style `width: 60px; height: 60px; border-radius: 50%; object-fit: cover; flex-shrink: 0;`
- When null: same circle dimensions, `background-color: {avatarBg}` (bench `#94a3b8` / advocate `#93c5fd`), initials text 18px weight 600 `#0f1117`.

**No close button inside the card** — Escape key dismissal (bits-ui native) is sufficient. No caret/arrow on the popover.

### ChatBubble.svelte (modified)

- Avatar `div` (line 47) becomes a `<button type="button" aria-label="View {displayName} details">` — `aria-hidden="true"` removed.
- Button receives an `onAvatarClick` prop: `(personId: number) => void`.
- Visual styles on the button element: `background: none; border: none; padding: 0; cursor: pointer;` — the interior circle div retains its existing styles.
- `utterance` prop gains `person_id: number` (from the new speakers endpoint loaded server-side).

### Argument page `+page.svelte` (modified)

- Imports `Popover` from `bits-ui` and `SpeakerPopover.svelte`.
- Single `Popover.Root` at page level; `currentSpeaker: SpeakerDetail | null` tracked via `$state(null)`.
- `onAvatarClick(personId)` callback sets `currentSpeaker = speakersMap.get(personId) ?? null` and opens the popover.
- `Popover.Content` renders `<SpeakerPopover speaker={currentSpeaker} />` when `currentSpeaker` is not null.
- Roster section updated: each speaker row becomes `display: flex; align-items: center; gap: 8px;` wrapping a `Popover.Trigger` avatar button (32px circle, same color logic as ChatBubble) and the existing name `<p>` element. The trigger wraps the avatar circle only — the name text is not part of the button.

## Interaction Contract

### Trigger → Open

| Trigger | Location | Action |
|---------|----------|--------|
| Click / Enter / Space on avatar button | ChatBubble (per utterance) | Sets `currentSpeaker`, opens shared `Popover.Root` |
| Click / Enter / Space on roster avatar button | Header roster row | Sets `currentSpeaker`, opens shared `Popover.Root` |

### Dismiss

| Method | Behavior |
|--------|----------|
| Escape key | Closes popover; focus returns to trigger (bits-ui default — PUB-04 satisfied) |
| Click outside | Closes popover (bits-ui default) |
| Tab away | Closes popover (bits-ui default) |

### Focus flow

- On open: focus moves to `Popover.Content` (bits-ui handles `focus-trap` / initial focus).
- On close: focus returns to the avatar button that was activated.

### Touch target

- Avatar button minimum hit area: 44px × 44px via `padding: 6px` on the `<button>` element (visible circle remains 32px).

## Accessibility Contract

| Requirement | Implementation |
|-------------|----------------|
| PUB-04: keyboard accessible | bits-ui Popover handles Escape, Tab, focus trap natively |
| PUB-04: dismissible with Escape | bits-ui Popover default behavior — no custom handler needed |
| Avatar button label | `aria-label="View {displayName} details"` on each trigger button |
| Photo alt text | `alt="{full_name}"` on photo `<img>`; initials circle `aria-hidden="true"` |
| Popover content role | bits-ui assigns `role="dialog"` on `Popover.Content` |
| Apolitical constraint | `appointing_president_party` NEVER rendered in the popover — only "Appointed by [president name]" |

## Copywriting Contract

| Element | Copy |
|---------|------|
| Avatar button aria-label | "View {full_name} details" |
| Photo img alt | "{full_name}" |
| Initials fallback (aria) | aria-hidden="true" — initials are decorative; button label carries the accessible name |
| Tenure row format | "{seat} — {start_year}–present" (active) or "{seat} — {start_year}–{end_year}" (inactive) |
| Appointing president line | "Appointed by {appointing_president}" |
| Role line (when null) | Omit the role line entirely — do not show "No role" or "Unknown" |
| Error: photo load failure | `<img>` `onerror` falls back silently to initials — no visible error text |
| Empty popover state | Not applicable — popover only opens when speaker data is present in `speakersMap` |
