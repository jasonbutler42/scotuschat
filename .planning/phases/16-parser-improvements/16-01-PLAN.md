    (`^[\xad\-\s–—xX\*]+$`), `CAPTION_PUNCT_RE` (`\s*[:),]\s*$`). Define `_MONTH_MAP` mapping the
    first three lowercase letters of each month name to its integer 1-12.

    - `_clean_lines(raw: str) -> list[str]` — split on newline, apply `strip_line_number` + strip,

    - `_parse_date(m: re.Match) -> date` — build `date(int(year), _MONTH_MAP[month_lower_first3], int(day))`
      from the match groups (group 1 = month name, group 2 = day, group 3 = year).
    - `_extract_case_name(lines: list[str]) -> str | None` — find the line containing
      "SUPREME COURT OF THE UNITED STATES" (uppercased compare); from the next line, skip
      `CAPTION_SEP_RE` separator lines; then accumulate name lines, stopping at a line beginning
      with "v." or "Petitioner" or a separator line; strip trailing caption punctuation via
      `CAPTION_PUNCT_RE`; join accumulated parts with a single space; return None if nothing accumulated.

    Implement the public function `extract_cover_metadata(pdf_path: Path) -> dict`. It returns a dict
    with zero, one, or two keys (`argued_date` -> date, `case_name` -> str). Wrap all pdfplumber/regex
    logic in `try/except Exception: pass` and return the (possibly partial) result — NEVER raise (D-05).
    Open the PDF once with the context manager, read raw text of pages `range(min(3, len(pdf.pages)))`
    using `extract_text(layout=False) or ""`. For each page: if `argued_date` not yet found, search with
    `DATE_LINE_RE` then `HERITAGE_DATE_RE` and on match set `result["argued_date"] = _parse_date(m)`;
    if `case_name` not yet found, run `_extract_case_name(_clean_lines(raw))` and set it if truthy. Break
    once both keys are present.

    Document the silent-fail contract in the function docstring referencing D-05.

| T-16-04 | Tampering | Unintended DB write during operator --dry-run preview | medium | mitigate | All UPDATE blocks placed after the dry-run gate (Pitfall 3); CPU-only extraction precedes the gate |
