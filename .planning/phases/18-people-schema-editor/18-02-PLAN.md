<objective>
Wire `is_justice` through the admin people API: add it to the `PersonDetail`, `PersonUpdate`, and `PersonListItem` Pydantic schemas; have `get_person_detail` and `list_people` return it; and have `update_person` write it through the existing mass-assignment allow-list.

Purpose: PEOPLE-05 / PEOPLE-07 (backend) — the editor (Plan 03) reads `is_justice` from the API to seed the toggle and writes it back on Save. Without this wiring the frontend has no field to bind to or persist.

Output: Three extended schemas, two service read paths returning `is_justice`, one service write path, and extended schema/service tests.
</objective>
