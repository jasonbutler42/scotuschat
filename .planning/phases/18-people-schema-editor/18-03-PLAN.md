<objective>
Implement the people-editor UI for `is_justice`: an "Is Justice" checkbox bound to reactive `$state`, real-time `{#if isJustice}` show/hide of the Role select, Court Tenure card, and Appointment card, submission of `is_justice` in the `?/save` PATCH body, and a "Justice" badge on directory rows.

Purpose: PEOPLE-06 (conditional bench sections) and PEOPLE-07 (operator toggle) — the operator can correct a person's classification and immediately see the bench-only sections appear or disappear, then persist the change on Save.

Output: Reactive checkbox + conditional wrappers in the editor, `is_justice` in the save action's FormData/PATCH body, and a Justice badge in the directory listing.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser form → SvelteKit server action | is_justice checkbox value crosses into the save action and the FastAPI PATCH |
| FastAPI → SvelteKit server load | is_justice arrives in the people-list and person-detail JSON consumed by the directory and editor |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-18-CSRF | Spoofing | ?/save form action | medium | accept | SvelteKit's built-in CSRF origin check (existing for all admin form actions) and the server-side ADMIN_TOKEN proxy already guard this action; this plan adds a field to an existing form, no new attack surface. |
| T-18-CLIENTGATE | Tampering | {#if isJustice} hiding bench sections | low | mitigate | The frontend hiding is presentational only; the backend (Plan 02) preserves role_id and tenure rows in the DB regardless of is_justice (D-06/D-07). A tampered client that submits hidden fields still cannot corrupt bench data because absent fields = leave unchanged and the allow-list governs writes. |
| T-18-TOKENLEAK | Information Disclosure | FASTAPI_BASE_URL / ADMIN_TOKEN | high | accept | Existing pattern — all FastAPI calls go through +page.server.ts; ADMIN_TOKEN and FASTAPI_BASE_URL stay server-only (CLAUDE.md Architecture Rule 2). This plan adds no client-side fetch. |
| T-18-SC | Tampering | npm/pip/cargo installs | low | accept | No package installs — the is_justice checkbox is a native HTML input; no new dependency (UI-SPEC Registry Safety). |
</threat_model>
