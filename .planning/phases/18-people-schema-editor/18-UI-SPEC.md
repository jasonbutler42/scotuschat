## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Chip gap, toggle knob inset |
| sm | 8px | Label-to-input gap, inline button padding, field margin-bottom default |
| md | 16px | Default field margin-bottom, section header margin-bottom, grid gap |
| lg | 24px | Card padding, between-card margin-bottom |
| xl | 32px | — (not actively used in admin) |
| 2xl | 48px | Page container top/bottom padding (`padding: 48px 24px`) |
| 3xl | 64px | — (not actively used in admin) |

Exceptions:
- Touch targets for interactive buttons: `min-height: 44px` (WCAG 2.5.5 — existing pattern for all Save/Delete/CTA buttons)

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 | 1.5 |
| Label | 14px | 400 | 1.4 |
| Heading (card section) | 20px | 600 | 1.2 |
| Display (page h1) | 20px | 600 | 1.2 |

Notes:
- Body (16px) applies to: all text inputs, selects, textarea, table body cells, CTA button text
- Label (14px) applies to: `<label>` elements, secondary/muted text, table column headers, filter toggle labels, missing-field chips, link text in table rows, error/alert messages
- Heading and Display share the same spec (20px / 600 / 1.2) — this matches existing `<h1>` and `<h2>` usage throughout admin
- No display size above 20px is used in admin UI

Source: inline styles in `app/src/routes/admin/people/[id]/+page.svelte` and `+page.svelte`.

The `is_justice` checkbox does not use accent styling — it uses the browser default checkbox appearance, consistent with how existing HTML form elements render in this project.

## Component Inventory

New UI elements this phase must follow existing inline-style patterns exactly. No new component abstractions introduced.

### 1. Is Justice Checkbox (new — editor)

- Element: `<input type="checkbox" name="is_justice" id="is_justice" bind:checked={isJustice}>`
- Placement: Top of Basic Info card, before Full name field — below `<h2>Basic Info</h2>`, above Full name `<div>`
- Wrapper: `<div style="margin-bottom: 16px; display: flex; align-items: center; gap: 8px;">`
- Label: `<label for="is_justice" style="font-size: 16px; font-weight: 400; color: #e2e8f0;">Is Justice</label>`
- Checkbox renders at browser default size (no custom styling); no toggle-switch widget
- `bind:checked={isJustice}` where `isJustice` is `$state<boolean>` initialized from `data.person.is_justice`
- Source decision: CONTEXT.md D-03, D-04, Specifics section

### 2. Conditional Section Wrapper (new — editor)

- Pattern: `{#if isJustice}` wrapping the Role select field (within Basic Info card) and the entire Court Tenure card and Appointment card
- Sections that disappear: Role select div, Court Tenure card (`<div>` with heading "Court Tenure"), Appointment card (`<div>` with heading "Appointment")
- Reactivity fires on checkbox change — no save required to see sections appear/disappear
- DOM-absent inputs are not submitted; save action treats absent fields as "leave unchanged"
- Source decision: CONTEXT.md D-05, D-06, D-07, D-08, D-09

### 3. Justice Badge (new — directory listing)

- Element: inline `<span>` rendered inside the Name cell of the people table
- Content: text "Justice"
- Style: `display: inline-block; background-color: rgba(147,197,253,0.15); border: 1px solid #93c5fd; color: #93c5fd; border-radius: 4px; padding: 2px 6px; font-size: 14px; font-weight: 400; line-height: 1.4; margin-left: 8px;`
- Placement: after `{person.full_name}` text, on the same line, separated by `margin-left: 8px`
- Visibility: rendered only when `person.is_justice === true`
- Rationale: accent color (#93c5fd) differentiates Justice badge from warning badge (#f59e0b used for missing fields) — same chip shape, different semantic color
- Source decision: CONTEXT.md D-10

## Interaction States

| Element | State | Visual Change |
|---------|-------|---------------|
| Is Justice checkbox (checked) | Conditional sections appear | Role select, Court Tenure card, Appointment card become visible in DOM |
| Is Justice checkbox (unchecked) | Conditional sections hidden | Role select, Court Tenure card, Appointment card removed from DOM |
| Save button (submitting) | `disabled`, `opacity: 0.7` | Button text changes to "Saving…" |
| Save button (idle) | default | "Save changes" |
| Any input | focus | `outline: 2px solid #93c5fd; outline-offset: 3px; border-radius: 4px` (from app.css `*:focus-visible`) |
| Is Justice checkbox toggle | no confirmation | Immediate — no confirmation dialog needed; toggling is non-destructive |

## Accessibility

| Requirement | Implementation |
|-------------|----------------|
| Checkbox label association | `<label for="is_justice">` explicitly associated via `id` |
| Checkbox focus ring | Covered by `*:focus-visible` global rule in app.css |
| Justice badge — screen reader | Badge text "Justice" is inline text content; readable without aria annotation |
| Conditional sections | `{#if}` removes elements from DOM entirely — no `aria-hidden` needed; removed inputs not submitted |
| Touch target | Is Justice checkbox + label wrapper `min-height: 44px` via flex alignment (no explicit height needed; label text provides sufficient tap area with flex row) |
| Error alerts | `role="alert"` on error `<p>` elements — existing pattern carried forward |
