<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → SvelteKit form action | Operator-triggered POST `?/delete`; CSRF-protected by SvelteKit (ORIGIN env) |
| SvelteKit server → FastAPI admin router | Server-side fetch with `X-Admin-Token`; never exposed to client |
| FastAPI → PostgreSQL | Multi-table delete; FK integrity enforced by DB |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-21-01-IDOR | Tampering | DELETE /arguments/{id} | medium | mitigate | Path param typed `int`; service returns None → 404 for non-existent id; single-operator model, no user scoping needed |
| T-21-01-PUB | Tampering | delete_argument service | high | mitigate | Server-side `status == PUBLISHED` check returns False → 409 regardless of client button state; client disabled state is defense-in-depth only |
| T-21-01-FK | Denial of Service | multi-table cascade | high | mitigate | Fixed FK delete order (utterances → pipeline_runs → participants → case_arguments → NULL admin_jobs → argument); tested for no ForeignKeyViolation |
| T-21-01-CSRF | Tampering | ?/delete form action | medium | mitigate | SvelteKit CSRF active (ORIGIN set); POST-only form action |
| T-21-01-AUTH | Elevation of Privilege | DELETE endpoint | high | mitigate | Router-level `verify_admin_token` dependency inherited; no anonymous path |
</threat_model>
