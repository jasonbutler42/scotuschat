Props (D-03): `savedValues: { dockets: string[]; question_number: string; argued_date: string | null }`, `hints: { dockets: string[]; question_number: string | null; argued_date: string | null; case_name: string | null }`, `action: string`, `readonly = false`, `form = null` (carries `{ dockets?, saveError?, saved? }`). Declare the ArgumentDetailsCardProps interface in the script. Component naming PascalCase, props camelCase (Claude's Discretion in CONTEXT.md).

    State (D-04/D-05): `pills = $state(savedValues.dockets ?? [])`, `docketInput = $state('')`, `saving = $state(false)`. `addPill()` trims docketInput, silently rejects empty and duplicate values (`pills.includes(v)`), otherwise pushes and clears the input. `removePill(value)` filters the pill out. D-06: an `$effect` sets `pills = form.dockets` when `form?.dockets` is present (restore on failed save) — this is the ONLY restore path; do not re-derive pills from savedValues on failure.

    Form (D-01): `<form method="POST" {action} use:enhance={...}>`. The enhance callback sets `saving = true` on submit; in the returned async handler set `saving = false`, and on `result.type === 'failure'` call `await update()`, else `await update({ reset: false })` (reset:false is mandatory — reset:true wipes pill $state, Pitfall 4). Render one `<input type="hidden" name="docket[]" value={pill}>` per pill via `{#each pills as pill}` (D-05 — server reads FormData.getAll('docket[]')).

    Fields per UI-SPEC Layout Contract: (1) Docket — pill list (flex-wrap, gap 8px) with each editable pill showing text + a × remove button (aria-label="Remove docket {value}", min 28×28px touch, hover color #ef4444); below it the docket text input (placeholder "Add docket and press Enter…") whose onkeydown intercepts Enter with e.preventDefault() then calls addPill() (Pitfall 2). (2) Question number — plain `<input type="text" name="question_number">` bound to a local value seeded from savedValues.question_number (PJOB-06 free text, replaces the old integer dropdown). (3) Argued date — `<input type="date" name="argued_date">` seeded from savedValues.argued_date.

    Hints (D-07/D-08/PJOB-04): below EACH field render an always-present hint row. For question number and argued date: `Extracted: {value ?? 'N/A'}` in 14px #94a3b8; when value is null add font-style italic to distinguish N/A. For docket (D-09): render hints.dockets as read-only pills (smaller, no × button, 12px, color #94a3b8, background #0f1117, gap 4px) prefixed with "Extracted:"; when hints.dockets is empty render "Extracted: N/A" italic. Hint rows are NEVER conditionally hidden.

    Heading "Argument Details" (h2, 20px/600) per PJOB-03. Card wrapper background #1e293b, border 1px solid #334155, border-radius 8px, padding 24px. Inputs full width, background #0f1117, border #334155, border-radius 6px, padding 8px 12px, font-size 16px, color #e2e8f0, box-sizing border-box. All inputs have associated `<label for>`. Save button (full width, min-height 44px, border 1px solid #93c5fd, label "Save Argument Details", label "Saving…" and opacity 0.7 when saving). Success renders "Saved." in #4ade80; error renders form.saveError in a role="alert" paragraph color #ef4444.

    Readonly mode (for Phase 26 reuse, AEDIT-04): when `readonly` is true, all inputs get the `disabled` attribute, pill × buttons are not rendered, and the save button is not rendered — but hint rows still render so the operator keeps the historic extraction view.
