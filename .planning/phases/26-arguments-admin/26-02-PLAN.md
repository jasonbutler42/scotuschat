<objective>
Expose the data the argument edit page needs: the full status log, a unified Speakers list (bench + advocate) with per-participant utterance counts and advocate titles, and the ability to save an advocate's title alongside their role.

Purpose: The rebuilt edit page (Plan 26-04) needs three things the API does not yet return — a `status_log` array (AEDIT-01/AEDIT-02 UI surface), a `speakers` array replacing the old advocate-only `participants` + tenure-gap-warning split (AEDIT-05/06/07), and a participant-update path that persists advocate `title` (AEDIT-06). This plan is the data contract for that page.

Output: New `list_argument_speakers` helper and status-log fetch in `get_argument_detail` (admin_arguments.py); new `StatusLogEntry` + `SpeakerRow` Pydantic models and extended `ArgumentDetail` / `ParticipantSideUpdate` (schemas); router wiring to pass `title`.
</objective>
