<objective>
Build the backend data layer for the admin dashboard: a new Pydantic schema module and seven read-only aggregation service functions (COUNT/MAX/LIMIT queries) across the three existing admin service files, plus DB-gated tests proving their I/O contracts.

Purpose: The dashboard needs stat-card counts (DASH-01) and Needs-Attention top-5 slices (DASH-03). Existing list_* functions return every row with no LIMIT (Phase 24 PLIST-03), which is a corpus-scale performance regression (Phase 29/30 added ~7,800 argument rows). This plan provides the thin COUNT/LIMIT layer instead.
Output: api/schemas/admin_dashboard.py; new functions in admin_arguments.py / admin_people.py / admin_jobs.py; api/tests/test_admin_dashboard_stats.py.
</objective>
