    - Typo variants observed in real data — `(Luaghter)`, `[Inaudibel]` → detected (case-insensitive, typo-tolerant via a normalized/fuzzy match against the curated vocabulary, NOT a blind bracket/paren capture).

    - A turn whose text is ordinary speech that merely contains a parenthetical citation like "section (a)" → NOT detected as a stage direction.
  </behavior>
  <action>Create `pipeline/corpus/__init__.py` (empty package marker) and `pipeline/corpus/stage_directions.py` exposing a `CURATED_MARKERS` collection (base terms: inaudible, laughter/laughs/laugh, voice overlap, recess, luncheon recess, cross talk) and a function `detect_stage_direction(text: str) -> str | None` that returns the normalized marker label when the text is a stage direction, else None. Match only content inside `[...]` or `(...)`; normalize the captured inner token (lowercase, strip punctuation/whitespace) and compare against the curated vocabulary with typo tolerance (e.g. difflib close-match with a tight cutoff, or edit-distance ≤2) — never a blind "anything inside brackets/parens" classification (D-17). Reject numeric-only and single-letter tokens (a/b/1/2) and the literal phonetic marker used in transcripts to flag uncertain name spellings, so they are not misclassified.
