4. `api/tests/test_question_number_nullable.py` run directly: `3 passed` (CaseItem/ArgumentMetadataResponse accept `None`; `admin.py` source contains `IntegrityError`).
5. Full `api/tests/` suite: `133 passed, 105 skipped` — 0 failed, 3 more passing than the previous verification's `130` (the 3 new tests), consistent with a clean regression run.
6. Isolation re-check of `test_admin_arguments_service.py` + `test_arguments.py` (flagged in task context as flaky only in full-suite runs) run alone: `21 passed, 19 skipped` — consistent with the pre-existing, phase-unrelated shared-DB pollution issue, not a regression from this plan.
