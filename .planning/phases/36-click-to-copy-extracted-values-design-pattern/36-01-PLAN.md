<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Rendered operator data to browser clipboard | Already-rendered plain text crosses into a browser capability only after explicit operator activation |
| Component props to DOM | Extracted strings may contain untrusted PDF-derived text and must remain escaped Svelte text, never interpreted markup |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-36-01 | Tampering | Clipboard payload | high | mitigate | Use the exact rendered prop string for `writeText`; do not normalize, concatenate, use HTML formats, or read DOM HTML |
| T-36-02 | Spoofing | Copy feedback | medium | mitigate | Keep success/failure state local to the activated instance and show success only after the clipboard promise resolves |
| T-36-03 | Information Disclosure | Error feedback | low | mitigate | Display only fixed `Couldn't copy.` text and never expose raw browser exceptions |
| T-36-04 | Denial of Service | Repeated activation timers | medium | mitigate | Keep one timeout per instance, clear before rescheduling, and clean up on destroy |
| T-36-SC | Tampering | npm installs | high | mitigate | Install nothing; if an executor proposes a package, stop for slopcheck and a blocking human review of assumed or suspicious dependency output |
</threat_model>
