## Trust Boundaries

| Boundary | Description |
|---|---|
| Component activation to browser clipboard | Operator-visible plain text crosses into a browser capability after explicit activation |
| Asynchronous browser result to component state | Promise completions and timers may arrive after a newer attempt, prop change, or destruction |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-36-09 | Spoofing | Local clipboard feedback | medium | mitigate | Generation checks ensure feedback belongs only to the newest activation and current payload |
| T-36-10 | Denial of Service | Clipboard timers/promises | medium | mitigate | Retain one timer, clear it centrally, and invalidate pending completions on activation, prop change, and destruction |
| T-36-11 | Information Disclosure | Clipboard rejection | low | mitigate | Render only fixed local failure copy and never surface browser exception details |
| T-36-SC | Tampering | npm installs | high | mitigate | Install nothing; use only the existing Node, Svelte, Vite, and browser tooling |
</threat_model>
