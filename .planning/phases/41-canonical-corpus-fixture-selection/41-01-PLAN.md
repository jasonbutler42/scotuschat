## Identity model: the primary noun is the fixture SET

CORPUS-12 was originally framed around a single "canonical audit fixture" (singular). Phase 41's discuss-phase widened it to a set of four.

- **Primary noun (now):** the **fixture set** — four records of one uniform shape (ConvoKit conversation id, case name, docket(s), term, argued date) distinguished by a single `Role` value. NOT two structures (a "the fixture" plus a bolted-on "extra fixtures" list).
- **Decision:** **promote.** CONTEXT.md D-01/D-07/D-08 already performed this promotion during discuss-phase, and ROADMAP.md (Phase 41/42/43) plus REQUIREMENTS.md (CORPUS-12, DEVTOOL-01) were edited in that same session to match. This plan set confirms and encodes the already-promoted model; it does not re-open it with the operator.
- **Rationale:** matches CONTEXT.md's own stated widening (D-01) — a uniform record shape with a role discriminator is exactly what Phase 42 (reads one row) and Phase 43 (reads all four rows) both need from one document.
- **Consequence for this plan:** the scoring script produces one uniform per-conversation record type; the complexity ranking and the state-variety proposal are two *views* over that same record type, never two different record shapes.
</assumption_delta_decision>

`_stream_signals(utterances_path, wanted_ids, speakers, max_rows) -> dict[str, dict]` — initialize an entry for EVERY id in `wanted_ids` with a zero turn count and empty speaker/bench sets, so the returned mapping always covers all conversations including any with no utterance rows. Iterate `stream_utterances_for_conversation_ids(utterances_path, wanted_ids)` under `enumerate(..., start=1)`; per row increment the turn count and add `row["speaker"]` to the speaker set unless that speaker's `speakers[...]` type, lowercased and stripped, is in `UNATTRIBUTED_TYPE_VALUES` — the importer creates no Person row for that ConvoKit sentinel, so it must not inflate a dedup-pressure signal. Add the speaker to the bench set when its type is in `JUSTICE_TYPE_VALUES`. Print `f"...processed {i:,} utterance rows"` to stderr every `PROGRESS_INTERVAL` rows. Break after `max_rows` rows when that argument is not None. Return per-id `{"turn_count": int, "distinct_speaker_count": int, "bench_speaker_count": int}` — counts only, never the id sets, so Task 2 can persist this cheaply.

`_conversation_rows(cases_by_id, conversations, signals) -> list[dict]` — one uniform record per conversation id, built ONLY from extractor output. For each `(cid, conv)` in `conversations.items()`: call `extract_conversation_fields(conv)`, take `advocate_count` as the length of its `advocates` mapping or 0 (a conversations.json entry's own mapping, NOT the case-level one — RESEARCH Pitfall 2), then look up `cases_by_id.get(...)` on its `case_id` and, when found, call `extract_case_fields(raw_case)`. Note `extract_conversation_fields` returns `conversation_id=None` against real corpus rows because the id lives only in the dict key, so take the id from `cid`. Record fields: `conversation_id`, `case_id`, `case_name` (via `_case_name`), `docket_no`, `term` (the case `year`), `n_transcripts` (length of the case `transcripts` list or 0), `advocate_count`, `distinct_speaker_count`, `bench_speaker_count`, `turn_count`, and the `transcripts` list itself for Task 2's date derivation. A conversation whose case_id misses the index keeps zeroed case-derived fields and a `case_name` of `"(no matching cases.jsonl row)"`.

`_case_name(case_fields) -> str` — prefer `title`, else `f"{petitioner or 'Unknown'} v. {respondent or 'Unknown'}"`, matching `_case_name_from_fields`.

`_path_coverage_flags(row, thresholds) -> dict[str, bool]` — the four booleans in `FLAG_NAMES` order: advocate_count at or above the advocate threshold, distinct_speaker_count at or above the speaker threshold, turn_count at or above the turn threshold, n_transcripts at or above the transcripts threshold. `_magnitude_sum(row) -> int` — advocate_count plus distinct_speaker_count plus turn_count plus n_transcripts.

`_rank_candidates(rows, thresholds, top) -> list[dict]` — attach `flags` and `coverage` (the count of true flags) to each row, sort by the TOTAL ORDER `(-coverage, -magnitude_sum, conversation_id_ascending)`, and return the first `top` entries. Coerce the id component to an int when it is all digits so ordering is numeric-stable for this corpus's numeric ids, falling back to the string otherwise. Never collapse the four signals into a single weighted composite score: D-03 forbids that explicitly, coverage breadth outranks magnitude on any one axis, and magnitude only ever breaks a coverage tie. An empty `rows` list returns an empty list; a `top` larger than `len(rows)` returns every row.

`_print_shortlist(ranked, thresholds)` — a markdown table on stdout whose header row begins `| Rank ` with columns Rank, Coverage, Conversation ID, Case Name, Docket, Term, Advocates, Distinct Speakers, Bench Speakers, Turns, Transcripts, Flags hit. Render Coverage as `N/4`. Render Flags hit as the comma-joined true names from `FLAG_NAMES`, or an em dash when none are true. Every data row begins with a pipe, a space, then the rank digit. Emit no timestamp, elapsed time, hostname, or absolute path anywhere on stdout — Task 2's determinism gate compares two runs byte for byte, so progress lines and warnings go to stderr only.

`_self_check() -> int` — a corpus-free assertion harness over synthetic inputs, printing one line per check that begins with the four characters `PASS` followed by a space when the check holds, and a differently-prefixed line when it does not, returning 0 only when every check held. At minimum four checks: (1) *total order* — synthetic candidates including a coverage tie and, inside it, a magnitude-sum tie rank in coverage-descending, magnitude-descending, id-ascending order, and two successive calls return an identical id sequence; (2) *degenerate inputs* — ranking an empty list returns an empty list without raising, a one-element list returns that element, and requesting 5 from 2 candidates returns 2; (3) *zero coverage* — with thresholds above every synthetic value all four flags are false, coverage is 0 on every row, and the requested row count is still returned; (4) *apolitical containment* — build a synthetic raw case dict that deliberately carries every name in `FORBIDDEN_FIELDS` alongside the allowed ones and assert the intersection of `set(extract_case_fields(that_dict))` with `FORBIDDEN_FIELDS` is empty, then the same for `extract_conversation_fields` over a synthetic raw conversation dict; derive those names by iterating the imported frozenset, never by writing them out.

`main(argv=None) -> int` — when `--self-check` is set, run `_self_check()` and return its code without touching the corpus at all. Otherwise resolve and validate the corpus directory and its four files, load, stream, join, rank with the module thresholds and `DEFAULT_TOP`, print the shortlist, and return 0.
