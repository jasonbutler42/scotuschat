<objective>
Delete the fixture, re-import it through the fixed code path, re-run the same comparison,
and prove — rather than assert — that every approved real defect is now correct and that the
re-imported rows match the raw ConvoKit source exactly.

Purpose: this closes CORPUS-14 and ROADMAP success criteria 3, 4, and 5. Because corpus
import is idempotent-skip, a re-import without a preceding delete would silently no-op and
produce a false pass; because the automated test suite deliberately uses only small synthetic
corpus trees, the 479-turn exactness claim can only be proven against the real fixture.

Output: a regenerated `.planning/CORPUS-FIDELITY-DIFF.md` carrying before-and-after verdicts,
and operator confirmation that the transcript page's section anchors render.
</objective>
