<objective>
Restructure `ResolveCard.svelte`'s table into the five columns SEED-001's mockup specifies — Raw
Label, Resolved As, Bench/Advocate, Argument Role, Descriptor — deleting the Action column entirely,
folding its two buttons into a single person-search entry point inside Resolved As, and making the
Descriptor cell render on every row instead of disappearing for bench and gated rows.

Purpose: this is the structural half of the rework. The Bench/Advocate and Argument Role cells keep
their current contents in this plan (44-03 replaces those controls) — separating structure from
controls keeps each pass reviewable against the mockup and avoids rewriting the same `<td>` twice.
The Resolved As collapse (D-03/D-04) lands here rather than in a later pass because RESOLVE-01's
"row actions live inside the Resolved As cell" and D-03's "one entry point" are the same edit.

Output: a five-column table whose Resolved As cell owns every person-matching action, and a
Descriptor cell that is always present.

Decisions implemented (CONTEXT.md):
- D-03: the separate Confirm and Select buttons collapse into one entry point — the person-search combobox opens pre-filled with the auto-matched candidate, badged as the top suggestion; no Confirm button/action survives anywhere — Task 2.
- D-04: an untouched pre-fill counts as accepted when Continue Resolve is submitted, achieved by seeding the row's disposition from the auto-match candidate id rather than by a visible button — Task 2.

## Visual deltas resolved here (UI-SPEC omissions, not re-asks)

The UI-SPEC's Resolved As state list does not cover two states the mockup shows. Both are resolved
decisively below rather than deferred; if either resolution is wrong, the fix belongs in this plan.

1. **Gated row, Resolved As.** The mockup's UNKNOWN SPEAKER row shows the "Select person…" text
   *without* the leading magnifying-glass icon that the MR. BOPP row has. The UI-SPEC retired the
   old instructional sentence but did not say what replaces it. Resolution: the gated row renders
   the same text with no icon, `aria-disabled="true"`, no click handler, and a visually-hidden
   explanation — matching the mockup's icon-less variant while preserving the D-11/PJOB-18
   side-first gate.
2. **Disposition markers on discrepancy rows.** The pre-existing green "✓ Confirmed" / "✓ Corrected"
   markers are not listed in the UI-SPEC's Copywriting Contract in either direction. Resolution:
   keep both strings verbatim on the states that already show them (a *corrected* row keeps its
   marker above the combobox). A freshly pre-filled, untouched row shows the pre-filled input and no
   marker — the visible pre-filled value is the affordance, and no new copy is invented.
