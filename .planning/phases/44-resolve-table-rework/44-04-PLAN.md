<objective>
Give all four hinted columns the consistent extracted-value hint RESOLVE-05 requires, using the
honest `Imported:` wording D-09 locked, by adding one optional prefix prop to the shared
`CopyableExtractedValue` component rather than hand-rolling a fifth hint variant.

Purpose: RESOLVE-05's literal wording says "Extracted: …", but the discuss-phase established that
this milestone's fixture data reached `ArgumentParticipant` through corpus import, not through a
per-field PDF/LLM extraction event, and that no separate stored originally-extracted value exists for
side or argument role (D-08). `Imported:` is the honest framing for that. Routing it through a
default-valued prop on the shared component is what keeps every other call site in the admin UI on
`Extracted:` untouched — CLAUDE.md Architecture Rule 4 makes `CopyableExtractedValue` the default for
operator-editable extracted-value destinations, so extending it is the sanctioned move.

This plan closes the phase, so it also carries the visual acceptance checkpoint against
`resolve-speakers-panel.png` — the first point at which all five columns have their final controls
and hints and can be compared to the mockup as a whole.

Output: four single-line `Imported:` hints, an unchanged prefix everywhere else in the app, and
operator sign-off against the mockup.

Decisions implemented (CONTEXT.md):
- D-08: the confirmed finding that no separate stored originally-extracted value exists for side or argument role — `ArgumentParticipant` has no shadow column and no `pipeline_run_id` — is what makes each hint necessarily a redisplay of the row's own current value; the hint helpers are written to that reality rather than pretending to a provenance the schema cannot supply — Task 2 and the honest-framing prohibition.
- D-09: all four columns show a hint, and the wording is `Imported:` rather than `Extracted:` in this table only, delivered through a new optional prefix prop on the shared component so the five other call sites keep the default — Tasks 1 and 2. Real per-row provenance detection is explicitly deferred and is not built here.
</objective>
