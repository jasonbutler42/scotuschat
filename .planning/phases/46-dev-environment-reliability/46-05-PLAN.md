Today the operator hand-juggles process launches, and the session that motivated this phase lost real time to a listener on port 8000 that no Windows process API could identify or kill. Purpose: after this plan, starting and stopping the whole stack is one command with an honest answer to "what is holding this port".

Create `scripts/dev-start.sh` with a `#!/usr/bin/env bash` shebang and `set -euo pipefail`, and make it executable. Because the relocated repository now lives on a filesystem where the executable bit is meaningful and `core.filemode` was corrected to true in plan 46-04, the bit will actually be recorded in the index — confirm git stores it as mode `100755`, so a fresh clone gets a runnable script. Implement these functions and call them in this order on the start path.

`resolve_win_host_ip` — runs `ip route show default | awk '{print $3}'`, assigns the result to `WIN_HOST_IP`, and exits 1 with an error on stderr if empty. This reads the live routing table's default gateway, which in WSL2 NAT mode is the Windows host. Never read the DNS resolver configuration file instead, and never accept a cached or hardcoded address — 46-RESEARCH.md's Pitfall 2 records that the NAT subnet can shift across restarts.

`sync_env_db_host` — reads the host component of `DATABASE_URL` and `TEST_DATABASE_URL` from `.env`. If a host already equals `WIN_HOST_IP`, do nothing. If it differs AND matches the WSL2 NAT private-range pattern `^172\.(1[6-9]|2[0-9]|3[01])\.`, copy `.env` to `.env.bak`, restrict that backup to owner-only permissions because it is a copy of a secrets file, rewrite only the host component of those two variables in place with `sed`, and print a single line naming the old and new address — never print the surrounding DSN, which carries a password. If the host differs and does NOT match that pattern, refuse: print an error explaining that the configured host does not look like a WSL2 NAT gateway, that the script will not rewrite an `.env` pointing somewhere unexpected, and exit 1. Honour an opt-out: when `SCOTUS_DEV_NO_ENV_SYNC` is set to a non-empty value, skip the rewrite entirely and only warn on mismatch. This is the project's established refuse-loudly convention applied to a secrets file.

`probe_postgres` — a bash `/dev/tcp` reachability probe against `$WIN_HOST_IP:5432` wrapped in `timeout 5`, since this distro has no PostgreSQL client binaries. On failure, exit 1 with an error enumerating all three independent access gates by name — the `postgresql-x64-18` service being running, a `pg_hba.conf` host rule covering the WSL subnet, and a Windows Firewall inbound rule for TCP 5432 — because 46-RESEARCH.md's Pitfall 4 records that all three fail with an identical symptom.
