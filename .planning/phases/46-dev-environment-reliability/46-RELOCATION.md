| `app/.svelte-kit/` | Regenerated by the SvelteKit build. |
| `app/build/` | Regenerated by the build. |
| `data/pgsql/` | The retired in-repository PostgreSQL binaries, superseded by the Windows service under D-02. Copies at SRC are dealt with in plan 46-06. |
| `data/pgdata/` | The retired in-repository PostgreSQL cluster, superseded by the Windows service under D-02. Copies at SRC are dealt with in plan 46-06. |
| `__pycache__/` | Bytecode cache, some tagged from a mix of interpreters (WSL system Python vs. the project's pinned 3.12). |
| `*.pyc` | Same as above — interpreter-version-tagged cache files. |
| `.pytest_cache/` | Transient pytest cache, regenerated on next run. |
| `.mypy_cache/` | Transient type-checker cache, regenerated on next run. |
| `.ruff_cache/` | Transient linter cache, regenerated on next run. |
