Run from SRC as the current working directory. Exit code `0`.

## Exclude list and reason for each entry

| Excluded path | Reason |
|---|---|
| `.venv/` | Every console script carries an absolute interpreter shebang pointing into SRC; `pyvenv.cfg`/`bin/activate` bake the same path. Copying it would produce a venv that silently keeps executing from the old location. Rebuilt in Task 2. |
| `app/node_modules/` | Currently holds native packages for two different host platforms side by side (evidence of installs from both sides of the Windows/WSL boundary). Reinstalled in Task 2 from the committed lockfile. |
| `app/.svelte-kit/` | Regenerated by the SvelteKit build. |
| `app/build/` | Regenerated by the build. |
| `data/pgsql/` | The retired in-repository PostgreSQL binaries, superseded by the Windows service under D-02. Copies at SRC are dealt with in plan 46-06. |
| `data/pgdata/` | The retired in-repository PostgreSQL cluster, superseded by the Windows service under D-02. Copies at SRC are dealt with in plan 46-06. |
| `__pycache__/` | Bytecode cache, some tagged from a mix of interpreters (WSL system Python vs. the project's pinned 3.12). |
| `*.pyc` | Same as above — interpreter-version-tagged cache files. |
| `.pytest_cache/` | Transient pytest cache, regenerated on next run. |
| `.mypy_cache/` | Transient type-checker cache, regenerated on next run. |
| `.ruff_cache/` | Transient linter cache, regenerated on next run. |
| `*.egg-info/` | Build metadata, regenerated on next install. |
| `.dev-logs/` | Transient server output that can contain connection strings; no reason to propagate a second copy. |
| `.claude/worktrees/` | Transient agent worktrees; a stale worktree registration copied into `.git/worktrees` would make `git worktree list` at DST point back into SRC. |

Everything else transferred, including every untracked-but-load-bearing file:
`.env`, `app/.env`, `data/corpus/`, `data/pdfs/`, `data/uploads/`, the two
`data/tenure_office_*_dry_run.json` files, `memory/`, `.claude/` (minus
worktrees), `.codex/`, the untracked `.planning/` material (`intel/`, `notes/`,
the two `*-PATTERNS.md` files, the workstreams backup), and the root PNG files.
