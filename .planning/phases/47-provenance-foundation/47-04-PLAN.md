<conversion_rules>
These rules apply to every file in both tasks. Do NOT delete a test to make the suite green — a
deleted assertion is lost coverage, and every one of these has a direct translation.

| Old | New |
|-----|-----|
| `PipelineRun` | `ImportRun` |
| `PipelineRunStatus` | `ImportRunStatus` (five members and values unchanged) |
| `pipeline_run_id=` / `.pipeline_run_id` | `import_run_id=` / `.import_run_id` |
| `"pipeline_runs"` (table-name string) | `"import_run"` |
| `PipelineRun(..., strategy="convokit_import")` | `ImportRun(..., source=ImportSource.CORPUS, method=ImportMethod.DIRECT, external_id=<conversation_id>)` |
| `PipelineRun(..., strategy="rule_based")` | `ImportRun(..., source=ImportSource.PDF_PIPELINE, method=ImportMethod.RULE_BASED)` |
| `PipelineRun(..., strategy="llm_corrective")` | `ImportRun(..., source=ImportSource.PDF_PIPELINE, method=ImportMethod.LLM_CORRECTIVE)` |
| a `PipelineRun(...)` with no `strategy` for an ingest or resolve step | `ImportRun(..., source=ImportSource.PDF_PIPELINE, method=ImportMethod.NORMALIZED)` |
| `assert utterance.strategy == "rule_based"` | `assert run.method == ImportMethod.RULE_BASED` (assert on the parent run; the per-utterance column is gone) |
| `assert utterance.strategy in ("rule_based", "llm_corrective")` | `assert run.method in (ImportMethod.RULE_BASED, ImportMethod.LLM_CORRECTIVE)` |

Every `ImportRun(...)` constructed in a fixture MUST pass both `source` and `method` — they are
NOT NULL with no server default, so an omission fails at flush with an integrity error rather
than defaulting to something plausible.

Do not add provenance assertions to files other than those listed — `test_import_run_provenance.py`
is the single home for new provenance coverage, and plans 47-01 and 47-02 already populated it.

**Retired-name hygiene.** The acceptance criteria negative-grep for the retired identifiers
file-wide, so they are only satisfiable if those names disappear from prose too: when rewriting a
docstring, a section comment, or an assertion message, **restate it in the new vocabulary — never
annotate it with the old name**.
