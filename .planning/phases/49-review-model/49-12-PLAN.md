<decisions_recorded>
**D-49-12-a — `flex-wrap: wrap`, not container scroll, for the nav.** 49-08 chose container
scroll (`min-width: 0` outer + `overflow-x: auto` + `width: max-content` inner) for the status
segmented control because those five buttons share border geometry — first `border-radius:
6px 0 0 6px`, last `0 6px 6px 0`, middle four `border-left: none` — so a wrapped line would show
a detached half-rounded fragment. That constraint does not exist here: the sub-nav's children are
five independent `<a>` elements plus a `<form>`, with no shared border geometry, so a wrapped
line is visually clean. And for a NAVIGATION bar the two options are not equivalent in kind — a
horizontally-scrolling nav hides destinations behind a gesture with no affordance saying they
exist, which is a worse outcome for wayfinding than a taller nav. Wrap wins on both counts.
Measured above: wrap yields no page overflow at 360/375 and pixel-identical desktop geometry.

**D-49-12-b — keep `margin-left: auto` on the logout form.** Under `flex-wrap: wrap` an auto
margin resolves within the item's own flex line, so Log out sits at the right end of whatever
line it lands on (measured: right edge 336 at a 360px viewport, i.e. flush to the content box)
and stays flush right on the single line at desktop. That is the sane result, not merely a
non-overflowing one, so the declaration stays. Removing it would have left Log out jammed against
"Help" mid-line.

**D-49-12-c — TopNav is brought into compliance even though it is not currently overflowing.**
Measured: TopNav does NOT cause page scroll today. Do not claim it does. It is included for two
honest reasons: (1) it has exactly ZERO pixels of slack at 375px, so one added link or one font
fallback puts it over, and it already degrades at 360px by breaking the wordmark across two
lines; (2) it is in the computed chrome set by construction, and the whole point of a computed
sweep is that membership, not judgement, decides. Exempting the one near-miss the sweep found on
its first run would be the 49-08 mistake in a new costume.
</decisions_recorded>
