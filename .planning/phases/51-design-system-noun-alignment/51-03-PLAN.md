value-to-token map that every later conversion reads from.

times, `#334155` 240 times, `#e2e8f0` 210 times, and all three are existing custom properties
written longhand. This plan makes the token layer complete and authoritative so the conversion
work in plans 51-06 through 51-09 is mechanical rather than interpretive.

Output: a `:root` with a primitive palette feeding semantic roles, a five-step type scale, a
seven-step spacing scale, no Tailwind, and a token map file.
</objective>
