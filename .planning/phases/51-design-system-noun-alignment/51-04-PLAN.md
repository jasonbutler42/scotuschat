<objective>
Add the term-grouped read API the public listing IA needs: an index of October Terms with
published-argument counts, and a term-scoped list of that term's arguments.

Purpose: DS-04 and the API half of DS-01. `GET /cases` today returns every row with no limit,
offset, filter, or grouping. D-15 says design for the full corpus — roughly 7,800 arguments, not
today's four — so the term filter is required infrastructure, not decoration. D-14 makes term the
organising unit because it is the Court's own, and because grouping caps any single page at
around 150 rows with no pagination widget to design.

Output: two new endpoints, their Pydantic models, and the tests that pin both the published gate
and the structural trust-leak ban over them. The old `GET /cases` endpoint stays live until its
last consumer is removed in plan 51-08.
</objective>

**Live leak ban — the half a schema sweep structurally cannot see.**
`api/tests/test_trust_public_leak_ban.py` is the STATIC half: it derives response models from the
public routers and sweeps their DECLARED fields, descending through nested model annotations. What
it structurally cannot see is a payload that never passes through a declared model at all — a
public route registered with no `response_model` or with `response_model=None`, a raw
`JSONResponse` or bare `Response` return that bypasses response validation, a field typed
`dict`/`Any`/`list[dict]` whose runtime keys no declared-field sweep can enumerate, or a new public
route on a router not listed in `PUBLIC_ROUTER_MODULE_NAMES`. That is exactly why
`api/tests/test_arguments.py` carries a separate LIVE half that hits the real endpoint and walks
the decoded JSON recursively. Read that module's comment block before writing these.

Do not mistake the gap for something it is not: a declared `response_model` does NOT let extra keys
through. FastAPI validates the return value into the declared model and serializes only that
model's fields, so spreading an extra key into a return value while the model stays declared
changes nothing observable. The gap is the absence of a declared model, not a leak past one — which
is why Task 3's non-vacuity criterion removes the model rather than only adding a key.

`api/tests/test_public_arguments_listing.py`, importing the existing helper rather than copying
