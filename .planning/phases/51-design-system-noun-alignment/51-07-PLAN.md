plan is almost entirely rendered behaviour. The acceptance criteria below use three permitted
proof shapes only: a passing real-browser test, a build or typecheck exiting 0, and a **structural

across a computed file set is exactly what source text can prove. The presence of a string is
never used here as evidence that a page renders.

  <action>
Convert all five `lib/public/` components so every colour, size, weight, and spacing value is a
`var(--token)` reference. The inline `style="..."` attribute mechanism itself is retained: this is
a value substitution inside the same mechanism, not a migration to CSS-in-JS and emphatically not
a migration to a utility-CSS framework. Component-scoped style blocks get the same treatment — a
hex inside a style block is as much a bypassed token as one inside a style attribute.

Apply the reading polish D-09 asks for, within these five components:

- **Type.** Utterance body text uses `var(--font-size-lead)` with `var(--line-height-lead)` — Lead
  is reserved for the public reading layer. Speaker names and meta text use
  `var(--font-size-caption)`. Nothing in the public reading layer uses weight 500; there is no
  token for it.
- **Vertical rhythm.** Space between turns comes from the spacing scale, with a larger step at a
  speaker change than between a continued speaker's turns. Use `--space-*` tokens; a value that is
  not on the scale is a residual to report, not to round.
- **Speaker-change emphasis.** The emphasis is structural — spacing and the neutral side indicator
  — never typographic weight. A Justice turn and an advocate turn carry identical size, weight,
  and emphasis. Any treatment that reads as one speaker class mattering more fails the apolitical
  constraint, which extends to visual weight.
- **Stage directions.** `var(--color-stage-accent)` for the bracket, `var(--color-stage-text)` for
  the body, at `var(--font-size-caption)`. Quieter than utterances, still legible.
- **Measure.** Constrain the reading column so a line of utterance text does not run the full width
  of a wide viewport. Use a layout value — a `max-width` in `ch` or `px` — not a spacing token; the
  token map's out-of-scope section covers this distinction.

**No truncation, anywhere (P-06).** Do not introduce an ellipsis overflow, a line clamp, or a fixed
height combined with hidden overflow on utterance text, stage directions, speaker names, or popover
content. Long content wraps. If any such construct is already present on transcript content, remove
it — truncating the transcript alters the record.

**Runes discipline.** These files stay Runes-only: `$props`, `$state`, `$derived`, `$effect`. Never
`writable`, `readable`, or `derived` from `svelte/store`, and never a reactive label. Do not capture
a prop that must stay reactive into a top-level constant.

Keep the chat bubble, the popover, and the rail structurally as they are. `SectionRail` keeps its
`IntersectionObserver` behaviour unchanged.
  </action>
