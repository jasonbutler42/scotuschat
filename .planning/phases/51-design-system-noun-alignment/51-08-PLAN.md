full corpus of roughly 7,800 arguments, not today's four.

Output: two public listing routes, a `TermRow` component in the operator's chosen variant, the
first real-browser test for the public listing, and a `/cases` API surface that no longer exists.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| public browser -> `/arguments/term/{year}` | Untrusted year path segment reaches a server load function and then the API. |
| SvelteKit server load -> FastAPI | Server-only; `FASTAPI_BASE_URL` must never cross into the client bundle. |
| error path -> rendered page | An upstream failure must not print internals to a public reader. |
| test suite -> deleted modules | Deleting code can silently delete the guarantee its tests carried. |
