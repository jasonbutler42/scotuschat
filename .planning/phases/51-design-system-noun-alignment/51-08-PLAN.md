Implement the arguments listing style D-14 decided and D-16 selected: `/arguments` as an index of
October Terms with published-argument counts, and `/arguments/term/{year}` as that term's list of
arguments. Then retire the `/cases` API surface now that its last consumer is gone.

already on the response model, and grouping caps any single page at roughly 150 rows so there is
no pagination widget to design. D-15 is the binding constraint behind the shape: design for the
full corpus of roughly 7,800 arguments, not today's four.

Output: two public listing routes, a `TermRow` component in the operator's chosen variant, the
first real-browser test for the public listing, and a `/cases` API surface that no longer exists.
</objective>
