  <action>
Write `app/scripts/tokenize-styles.mjs` — a Node script that rewrites literal values to token
references across a file set. Doing this as a committed, tested script rather than by hand is the
point: the same mapping is applied at all 800 sites, and the mapping itself is reviewable in one
place.

**Scope of a rewrite.** The script only ever rewrites inside the body of an inline `style="..."`
attribute or inside a component `<style>` block. It never touches text content, an attribute other
than `style`, a script block, a comment, or a string literal in TypeScript.

**The four behaviours, from the token map:**
1. *Colour.* Replace each mapped hex with its semantic `var(--token)`. Hex matching is
   case-insensitive and covers both the 3-digit and 6-digit forms. Two hexes carry a
   default-plus-exception rule, which the script implements by file path: inside
   `app/src/lib/public/`, the slate-400 value maps to `var(--color-side-bench)` and the blue-300
   value to `var(--color-side-advocate)`; everywhere else they map to
   `var(--color-text-secondary)` and `var(--color-accent)`. An unmapped hex is NOT rewritten — it
   is reported.
2. *Type.* Only inside a `font-size:` declaration, collapse 11px, 12px, 13px, and 14px to
   `var(--font-size-caption)`; 16px to body; 18px to lead; 20px to heading; 28px and 32px to
   display. Only inside a `font-weight:` declaration, map 400 to `var(--font-weight-regular)` and
   both 600 and 500 to `var(--font-weight-semibold)`, reporting every 500 site separately because
   the token map flags it for an operator sight-check.
3. *Spacing.* Only inside `padding`, `padding-*`, `margin`, `margin-*`, `gap`, `row-gap`, and
   `column-gap`, map 4, 8, 16, 24, 32, 48, and 64 px to `--space-xs` through `--space-3xl`.
   Shorthand values with multiple components are handled component by component. A value not on
   the scale is left alone and reported.
4. *Out of scope.* Never rewrite inside `border-radius`, `grid-template-columns`, `width`,
   `height`, `min-width`, `max-width`, `flex-basis`, a numeric `line-height`, or anything inside a
   `calc()`.

**Modes.** Support a report-only mode that changes nothing and prints every planned rewrite plus
every unmapped residual, and an apply mode. The script is idempotent: a second apply run over
already-converted files must produce no change.

Write `app/scripts/tokenize-styles.test.mjs` using `node --test`. Cover at minimum: each of the
four behaviours on a positive case; the two default-plus-exception colour rules on both path
branches; a font size inside a `font-size` declaration rewritten while the same number inside a
`width` declaration is not; a spacing shorthand with four components; a `calc()` left untouched; a
hex inside a script-block string literal left untouched; an unmapped value reported rather than
rewritten; and idempotency across two runs.

Register the script in `app/package.json` as a `tokens:convert` command.
