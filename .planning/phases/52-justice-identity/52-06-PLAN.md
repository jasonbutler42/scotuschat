<objective>
Converge the last surviving client-side initials splitter onto the single server-side
implementation, so D-12's "exactly one initials implementation exists in the codebase" becomes
literally true rather than true-of-public-surfaces-only.

Purpose: plan 52-02 deleted the two byte-identical splitters on the public transcript page and
the speaker popover, and built `api.domain.person_names.derive_initials` as the one correct
implementation — suffix-aware, so `John Marshall Harlan, II` yields `JH` and not `JI`. During
52-02's structural ban sweep a third, independent copy of the same whitespace-splitting logic
turned up in `app/src/lib/admin/ResolveCard.svelte`, on an admin-only surface that plan never
named. Its `personDisplay` snippet receives only a `full_name` string, so it could not be
converged without a payload change — a scope question rather than a correctness bug, which is
why 52-02 correctly filed it rather than widening itself. Operator decision on 2026-09-25 was to
fix it properly in its own plan rather than bolt it onto a finished one.

Output: an `initials` field on `ResolveRow` computed by the same function, a `personDisplay`
snippet that takes it as a parameter, a deleted `getInitials`, and a test proving both the
populated and the null case.

**Why this is small.** `ResolveRow` already carries `person_id`, so the service that builds it
already has the person in hand — this is the same shape 52-02 used for `SpeakerPopoverEntry`,
applied to one more payload. The plan is deliberately two tasks and no new concepts.

**How the visual is verified.** Per `CLAUDE.md`'s Testing Policy, the server-side truth is proven
mechanically in Task 1. The admin resolve surface sits behind session auth with no browser
harness, and building one for one avatar would cost more than it proves — so the rendered result
is carried as a `<verify><human-check>` on Task 2 and harvested into the phase UAT batch under
this project's `workflow.human_verify_mode: end-of-phase`. The structural singularity claim is a
ban sweep, which is the one thing source text legitimately can prove.
</objective>
